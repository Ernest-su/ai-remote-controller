# 参与贡献

## 报告问题

提供预期行为、实际行为、最小复现步骤、应用/runtime 版本、Android 系统版本、目标 ABI 与连接方式。日志删除 API 密钥、配对码、二维码密码和个人信息；注明真机、模拟器或 fixture 环境。

## 代码与文档改动

阅读[架构](architecture.md)、[构建](build.md)和[视觉与交互约束](visual-guidelines.md)，将每次改动聚焦到一个问题。行为或接口变化需同一提交更新对应使用指南、协议或开发文档。按[测试](testing.md)的影响范围矩阵执行相关回归，发布前执行完整门禁。界面改动优先使用 JVM 和 Android 模拟器，真机用于无法替代的平台或硬件专项。MkDocs 严格构建只在提交前检查。

文档维护当前使用方法与稳定约束，测试结果写在提交说明，不新增开发流水账。

不要提交生成的 APK、二进制、站点、凭据、私钥或个人环境路径。新增文档同步加入导航；细则见[文档维护](documentation.md)。
