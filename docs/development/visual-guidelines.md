# 遥控应用视觉与交互约束

本文件是 AIRC Android 界面的约束来源，修改界面时必须遵循；仓库根目录 `AGENTS.md` 与贡献指南均指向本页。

## 官方参考与适配边界

参考微信官方设计团队的 [WeUI](https://github.com/Tencent/weui) 与 [WeUI-Design](https://github.com/weui/WeUI-Design)，核对日期为 2026-10-12。WeUI 面向微信 Web/小程序；AIRC 使用原生 Android Compose 实现，因此下文的 dp、sp、触控区域和导航结构是项目适配约束，不代表微信官方 Android 应用规范或官方认证。

官方事实源：

- [浅色主题变量](https://github.com/Tencent/weui/blob/master/src/style/base/theme/vars/light.less)：品牌绿、浅灰背景、白色内容层、黑色文字层级。
- [Grid 变量](https://github.com/Tencent/weui/blob/master/src/style/base/variable/weui-grid.less)与 [Grid 样式](https://github.com/Tencent/weui/blob/master/src/style/widget/weui-grid/weui-grid.less)：三列、28px 图标、14px 标签及细边界。
- [Button 变量](https://github.com/Tencent/weui/blob/master/src/style/base/variable/weui-button.less)：48px 主按钮、17px 文字、8px 圆角。
- [Cell 变量](https://github.com/Tencent/weui/blob/master/src/style/base/variable/weui-cell.less)：16px 内边距、56px 行高基准及正文/提示层级。

采用干净、克制的色彩与组件层级：页面背景承托 Surface 分组（亮色为浅灰/白色，暗色为深灰层级），绿色表示主要动作，红色只用于电源、停止和错误等明确语义。不要使用大面积渐变、重阴影、多色功能卡片或装饰性拟物效果。

## 颜色与字体

主题唯一代码入口为 `sharedUi/src/commonMain/kotlin/ernest/airc/RemoteTheme.kt`。禁止在页面中写死亮色背景或白色按钮文字。Android 与桌面共用语义色；系统栏、弹窗、菜单、输入框、禁用态随有效主题一起更新。

### 外观模式

功能网格提供「设置」，其中「外观」为互斥单选：**跟随系统（默认）／亮色／暗色**。选择立即生效并保存在当前控制端，离线可修改；返回、旋转与重启后保留。跟随系统响应系统模式变化，手动选择不受系统变化影响。切换不重建导航或清除文字草稿、不触发设备连接；未知历史值回退跟随系统。

深色中性层级参考 [WeUI 深色变量](https://github.com/Tencent/weui/blob/master/src/style/base/theme/vars/dark.less)（2026-10-15 核对），具体文字与操作色为项目对比度适配，不直接反转位图。正文与所在背景、主按钮文字与填充的对比度目标至少 4.5:1；绿色状态点与可点击操作色分开。截图、应用图标和镜像内容保持原色。

### 产品界面信息层级

- 主页面只显示当前任务、可用动作与下一步；连接状态统一在右上角，禁止在每个功能页顶部重复全局调试状态。
- 功能页使用稳定标题、分组和一致的按钮层级。一次只有一个主要动作；列表先展示内容，高级配置、诊断与完整技术输出按需展开，不能占据默认首屏。
- 没有数据时给出简明空态和下一步；错误紧邻相关动作显示且可重试；进行中反馈不挤动导航或输入区域。
- 执行结果页保留完整可选择文本；其他页面仅保留折叠的操作详情，不把原始 JSON 或协议状态当主界面。安全确认仍显示具体目标及影响，不隐藏决策所需信息。
- 停止服务需要说明会断开遥控并二次确认；取消不执行。主题设置无需确认、保存按钮或设备联网。
- 设置图标沿用 24×24、1.7 单位线宽的矢量样式；单选项整行可点击、最少 56dp，提供单选语义，适配大字体换行。

使用 Android 系统字体，不打包微信字体。页面标题 20sp，分组标题与正文 17sp，辅助说明和功能网格标签 14sp，小型反馈和按键标签 12sp；分别使用 28、24–25、20–21、18sp 行高。正文正常字重，标题 Medium；不用大量加粗制造层级。

## 尺寸与组件

Android 应用图标使用 `androidApp/src/main/res/drawable/ic_ai_rc.xml` 的完整彩色矢量图，保留提供素材的绿色底板、电视与 AI 遥控器构图和原色，不应用页面图标的单色 tint 或主题反色；应用清单通过 `android:icon` 引用该资源。

- 页面横向留白 16dp，分组间距 16dp，分组内部间距 12dp；紧凑遥控首页使用 8dp 间距，以保证基础按键与文字输入入口可见；使用 4/8/12/16/24dp 间距体系。
- 顶部导航最小高度 56dp，普通可交互区域最小 48dp；支持系统字体放大，不以固定高度截断文字。
- 分组、主按钮与描边按钮圆角 8dp；圆形仅用于方向盘、确认和遥控按键。
- 功能网格固定三列，最后一行按实际入口数量排列，每格最小 104dp 高；图标 28dp、标签 14sp、图标标签间隔 12dp、细分隔线 0.5dp。标签允许随系统字体换行，三列必须等宽。
- 使用统一 24×24 viewport、约 1.7 单位线宽的矢量图标。图标与文字组成完整可点击项，装饰图标不重复朗读；禁止 Unicode/emoji 图标。
- 主动作使用 Action / OnAction 语义色和清晰按压反馈；次动作使用中性/描边按钮。离线动作显示禁用状态，必须同时禁止执行。
- 表单与结果页可滚动、响应键盘与安全区；较宽屏幕将内容居中并限制在 560dp，不能把功能网格拉成巨大卡片。

## 导航与功能分配

没有主导航 Tab 或底部 Tab。首页为遥控器，左上角功能网格菜单图标进入功能页；右上角连接状态始终可点击，无论已连接或未连接，都进入设备页。

| 功能网格位置 | 功能 | 内容 |
| --- | --- | --- |
| 第一行左 | 应用管理 | 刷新应用列表、搜索、点击启动与按包名打开应用 |
| 第一行中 | 文字指令 | 发送自然语言任务、查看结果 |
| 第一行右 | 模型配置 | API 地址、密钥、模型 |
| 第二行左 | 服务管理 | 发布源、版本、状态、安装/更新、重启/停止 |
| 第二行中 | 运行权限 | 优先 root 开关与实际 UID 状态 |
| 第二行右 | 设备信息 | 连接信息、只读系统与硬件摘要、手动刷新 |
| 第三行左 | 执行结果 | 当前完整结果 |
| 第三行中 | 使用帮助 | 使用说明 |
| 第三行右 | 设备截图 | 截图与动态预览 |
| 第四行左 | 目标文件 | 文件浏览与传输 |
| 第四行中 | 设置 | 跟随系统、亮色与暗色外观 |

遥控器参考 `AIVoice/AIVoiceClient/phoneRemoteApp` 的尺寸与排列：宽度最多 390dp，外边距 14dp，内部水平 24dp、垂直 22dp；方向盘 220dp，方向键 60dp，确认键 82dp，返回/主页/设备菜单圆键 58dp，媒体圆键 52dp，发送图标触控区 48dp。顶部电源和音量、中央弹性状态区、下部方向盘与返回/主页/设备菜单、底部文字输入框与发送图标依次排列。普通窗口只滚动状态文本，媒体三键单独布局保留完整标签；遥控按键区最小高度 600dp，确保播放文字与媒体按键不互相裁切；短窗口或大字体允许上方遥控按键区域滚动，底部输入区独立固定，避免挤压触控区域。保留 WeUI 语义颜色与 8dp 卡片圆角，不复制参考界面的渐变、深蓝卡片和重阴影。

状态区默认显示实际播放状态和上一曲/播放暂停/下一曲。文字执行状态每次更新后，优先显示思考、工具调用、结果或错误，五秒无更新后回到播放，计时随新状态重新开始；媒体状态更新只更新底层播放数据，不抢占反馈。临时反馈期间隐藏媒体三键，静音与音量留在顶部。状态区高度保持弹性，状态切换不移动方向盘和文字输入区。反馈区可打开完整执行结果。

服务端以请求关联的可选进度事件报告思考和工具调用，较早请求的进度/完成不能覆盖更新的操作反馈。旧版服务不推送阶段时显示本地等待状态，最终响应到达后显示结果，不伪造中间进度。播放状态每三秒查询目标 MediaSession；查询失败显示不可用，不根据按键成功推断播放。

文字输入框使用中性描边与 8dp 圆角，可输入 1–3 行，右侧发送图标使用主操作绿，触控区 48dp，提供“发送文字指令”的无障碍描述。点击图标和键盘发送键使用同一提交逻辑。空白、离线、未配置模型或请求进行中时禁止发送；被接受后清空草稿、收起键盘。非敏感草稿在切页和旋转后保留。键盘由 Activity 的 edge-to-edge / adjustResize 与最外层 safeDrawingPadding 统一处理，子页面不重复使用 imePadding；输入区放在按键滚动区域之外，键盘展开时底部仅保留 8dp，收起后恢复普通面板留白。不申请录音权限，不保留 ASR 状态或配置。

服务管理以“管理服务”卡片展示服务端版本、GitHub 仓库链接与管理操作，完整输出通过“查看操作详情”按需展开。在线安装解析项目仓库最新 Release 的签名清单，不提供单独的清单 URL 表单或更新源保存按钮。

设备页顶部使用中性设备图标、扫描状态与刷新按钮；历史记录、局域网服务和同网段 ADB 合并为一个白色细分隔列表，同一地址只显示一行。行内 24dp 设备图标、设备名/地址与 12sp 来源标签（小矢量图标 + 文字）；连接与更多操作触控区至少 48dp。扫描只探测 Wi-Fi IPv4 默认 ADB 5555，不自动配对、授权或部署；大于 1024 地址的网络限制为当前 /24 并说明。连接目标设备与网络诊断位于列表后。手动连接卡片默认折叠，点击标题展开/收起，旋转保留展开状态与非敏感草稿。

设备页包含 TCP、配对码、二维码、发现和历史记录；连接方式的选择控件属于表单，不是主导航 Tab。设备页返回打开它的原页面；功能网格子页返回功能网格，功能网格返回遥控器。系统返回与顶部返回行为一致。旋转恢复当前页面和非敏感表单草稿，配对码不保存；API Key 仅保存在 Android Keystore 加密的 App 配置中，不进入 saved state。

## 手势、反馈与验收

文字输入与发送图标可通过 TalkBack 和键盘操作；可点击项具有文字标签和 Button 语义。

连接与长任务通过状态文字、进度条和结果区反馈；不得仅靠颜色区分连接、执行或禁用状态。执行结果维持当前业务行为，不虚构成功提示或未实现的功能。

界面变更需检查：默认遥控器不含应用编辑/列表；状态入口在连接与未连接状态均可进入设备页；全部入口可进入对应页面；返回路径与旋转恢复一致；离线遥控按钮不可执行；首页文字发送、草稿恢复、键盘发送与禁用语义正确。通过 Android UI 测试及截图检查窄屏、大字体和键盘可用性，报告未覆盖的设备条件。

触控板使用中性填充、细边框与 8dp 圆角，最小 240dp 高；手势结束后提交，单次拖动只发一条滑动，短点击延迟 300ms 用于识别双击。长按在松开时以实际按住时长（500–5000ms）提交。第二根手指介入时取消本次手势。发送期间或离线/旧服务缺少工具时禁用触控，保留文字说明与中心点击/长按的可访问按钮。数字键盘使用三列、最小 56dp 高按键，附频道、删除与静音操作，遵循已有颜色与字体。

模型配置支持按 API 根地址保存与切换多套 App 本地配置、逐项删除、API Key 明文/密文切换、手动拉取并缓存模型列表以及手填/列表选择模型。密钥显隐状态默认密文，旋转后恢复密文；草稿由 ViewModel 内存承载。保存到 App 和更新到目标设备为独立动作，不自动同步；目标离线不影响本地管理或拉取列表。

桌面 JVM 控制端使用 Compose 窗口，默认 390×844dp 的手机竖屏比例，窗口缩放时内容按可用空间居中并限制在手机宽度，保持同一 RemoteTheme、绿色图标、三列菜单和 48dp 触控区域；Escape 对应页面返回。桌面连接使用宿主机 adb，不复制 Android NSD/摄像头实现。

设备显示名使用共享编辑对话框：单行输入、保存与取消，说明仅作用于本应用；空白、超过 64 字符或控制字符禁止保存。

截图通过三列功能网格进入，使用统一线条相机矢量图标。预览保持原比例，最高 360dp；获取按钮离线或工具不支持时禁用。显示获取进度、错误与保存结果，保存和分享只在预览可用时出现。不自动捕获，不宣称实时投屏。

网络诊断在设备页使用Surface 分组卡片；显示实际地址、阶段名称、文字状态、耗时与处理建议。未检查、失败和通过必须用文字区分。输入不完整或运行中禁用启动，运行时提供进度与取消。

目标文件页使用统一线条文件夹图标，默认 Downloads，可切换服务收件箱和确认后的全盘范围。这些选择是页内范围控件，不是主导航。上传使用系统文件选择器；覆盖与删除对话框展示目标路径、当前大小和不可恢复的影响，需逐项确认；进度显示字节或删除项数并提供取消。目录项用Surface 分组和懒加载列表，进入新目录或显示属性时滚动到顶部；范围选择与条目操作在窄屏或大字体时自动换行，各动作至少 48dp。明确区分空目录、尚未读取、加载中、错误与不支持访问的符号链接，离线禁用实际请求。

文件页的“媒体打开”先查询目标支持的播放器，再在Surface 分组展示文件路径、类型、来源与可选包名，用户点击明确的打开按钮后执行。没有支持的播放器时说明限制，不显示虚假播放成功；启动结果与实际播放状态区分。私有媒体流提供手动释放入口，不把投送称为实时投屏。

私有媒体可选择“本地播放副本”或“HTTP 媒体流”，切换后重新查询对应播放器。创建本地副本前显示 Downloads 的公开可读范围、占用空间和原文件保留说明，再由用户确认；显示副本准备/校验进度及取消。释放副本只删除服务创建的副本，不影响原文件。

文件媒体分组提供“查看保留的播放副本”：手动读取服务记录，显示准确的 Downloads 路径和大小，逐项释放；不自动清理播放中的副本，不自动重新播放恢复记录。

媒体播放器查询结果属于系统声明能力；界面说明实际解码需核对，播放失败可选择其他播放器，不以列表匹配或 Activity 启动报告成功。

应用管理支持查看包名、版本、当前 Android 用户及类型；仅用户应用显示卸载动作。卸载对话框展示准确包名、版本、用户与删除数据的影响，确认后才提交；提交后显示不可撤销的处理中状态，不提供虚假的取消/恢复。模型提案通过独立待确认入口展示，禁止自动执行。

APK 文件条目提供“APK 信息”，共享信息分组展示路径、包名、版本、大小、摘要和声明证书指纹。明确区分解析与签名验证，不以成功色暗示可信或已安装。

APK 摘要阶段显示字节进度和至少 48dp 的“取消 APK 解析”按钮，取消后说明原文件保留。

APK 安装以独立“准备安装此 APK”按钮启动，覆盖安装须显式勾选。确认对话框可滚动，展示包名、当前/目标版本、Android 用户、摘要、声明证书与跨用户程序代码/数据迁移影响；准备阶段可取消，提交后显示不可取消状态。

目标文件页提供只读“存储分析”分组，主动分析当前目录，显示分析范围、扫描项数、取消、逻辑大小与文件块统计。报告按后缀归类、最多二十个大文件；不完整报告用文字说明，不以统计量暗示可回收空间，不提供隐式清理按钮。

Android 遥控器类型选择页提供“播放控制”，复用媒体矢量图标；子页返回类型选择，设备页返回来源页。标准会话选择、报告位置/时长、毫秒输入和提交/刷新各自明确显示；缺少定位接口或播放器不支持定位时禁止提交，提交请求与实际位置观察区分。位置草稿在导航和旋转后保留。

游戏手柄原型放在功能网格第五行第二项，使用统一线条手柄矢量图标。共享页面提供方向键、A/B/X/Y、肩键、Start/Select、按钮组合、归一化 X/Y 滑条和时长选择；滑条与组合选择只编辑草稿，显式发送后注入有限时长输入并自动释放/回中。运行中禁用重复发送，提供独立“释放按钮并回中”；离线所有实际动作禁用。组合及滑条/时长草稿在导航与旋转后保留。页面说明是输入原型，不承诺硬件手柄识别或低延迟游戏兼容。

应用管理中的“清理缓存”与卸载分开呈现，只对用户应用提供。独立确认对话框展示包名、版本、Android 用户，以及缓存可能包含离线下载/需要重新生成的影响；只用缓存接口，未支持时拒绝。显示等待确认和不可取消的提交阶段，不展示虚构的释放空间，不将清理缓存显示为删除应用数据。模型提案通过独立待确认缓存入口审核，页面导航保持不变。

持续虚拟手柄位于既有手柄页的独立Surface 分组，明确 root/uinput 条件与游戏兼容性限制。
用户手动开始/停止，按住按钮发送按下、松开或取消手势释放；键盘按下/抬起等价，
无障碍点击发送100ms有限按压。左右二维摇杆为132dp中性触控区，松开/取消回中，
另有独立“全部释放并回中”动作。所有按钮至少48dp、窄屏自动换行，复用统一主题。
活动输入、会话与画面不进入saved state；离页、旋转、Android后台或断线停止，手动重启。
持续会话期间禁用有限输入提交，避免两种输入同时作用。

## 系统管理确认

系统管理复用设备信息页的Surface 分组，不新增主导航。准备锁屏、重启或关机不会直接执行；确认弹窗必须显示当前目标名称、操作、root 权限与连接/任务影响。确认文字使用 Warning 色，确认与取消触控区域至少 48dp；等待确认期间禁用重复准备。断线或切换设备清空旧提案；若已尝试提交，保留明确标为先前目标的核对提示，离线时仍可阅读。提交反馈区分请求已提交与实际状态验证，不将断线显示为成功。

设备信息页的只读电源/锁屏状态使用现有Surface 分组和 InfoRow；未知布尔值显示未知，false 显示否，不解释为关机完成。刷新只在连接且非忙时可用，连接变化清空旧观察值。

系统观察分组明确显示最近一次快照及控制端收到时间，使用现有辅助字号和 InfoRow；不暗示后台实时轮询。清理观察时一并清理时间标签。

目录创建复用目标文件页分组，在刷新按钮下提供单行“新目录名称”与绿色“创建目录”；仅支持该工具的服务显示。名称草稿按根和目录区分并允许旋转恢复；离线、加载中、传输中或名称无效时禁用，创建后刷新当前目录，不切换导航。

手机手柄页限定为可随横向传感器翻转的横屏；进入触发实际 Activity 方向变化，离开恢复先前方向策略。原策略可保存在页面 saved state，活跃手柄输入不保存；旋转、后台或离页继续释放输入，恢复页面后手动开始。

触控区高度按页面可用高度减去 64dp 内边距预算计算，限制在 48–240dp；变量集中在 RemoteDimensions。横屏/短窗口允许缩小触控区，使整块可见并保留完整的 0–1 坐标映射，不只展示裁切片段。

Android ascrcpy 动态预览保持目标比例，以 SurfaceView 显示；参数与 ascrcpy App 一致，默认最长边 1920、码率 8 Mbps、最高 60 fps，触控高度至少 48dp。状态区区分准备、连接、预览与错误。后台、离页、Surface 销毁或旋转重建停止会话，返回后手动开始；不引入新导航或自动全屏。

Android 截图页的动态画面统一使用 ascrcpy，移除旧 PNG 连续预览和旧编码镜像参数控件。动态会话活跃时禁用单张截图，静止截图与视频共享原有页面入口。


Android 动态预览停止或失败后替换承载视频缓冲的 SurfaceView，释放旧 Surface，清除最后一帧；新空白 Surface 允许再次手动开始。旧视图迟到的销毁回调不得停止新会话。

持续手柄内容宽度至少 400dp 时将左摇杆与菱形主键并排，至少 520dp 时左右 132dp 摇杆与 A/B/X/Y 主按键同排，允许同时触摸；其他按键和方向帽继续换行。窄布局保持纵向排列。布局断点与摇杆尺寸集中在 RemoteDimensions，按钮仍至少 48dp，不改变背景释放规则。

应用列表在名称旁显示目标包管理器提供的 40dp 图标（96×96 PNG），作为装饰图像，不重复朗读；读取失败保留名称与原操作，不阻塞列表。每次先显示 30 项，使用“显示更多应用”继续展开，搜索仍匹配完整列表。刷新或目标连接变化清除图标内存缓存。

文件页的多包安装复用 APK 信息及确认分组：逐包解析后点击“加入多包安装”，展示 base/split 名称、路径、字节与摘要，提供至少 48dp 的移除按钮。必须包含一个 base、split 名称唯一、包名与版本一致；整组最多 32 个 APK、总量最多 4 GiB。覆盖安装仍显式勾选。最终确认展示整组文件，提交后不可取消；由同一个 Android 安装会话统一验证并提交。


Android 遥控器右上角增加 48dp“切换遥控器类型”矢量图标，连接状态入口保持可点击。选择页以白色列表展示标准遥控器、触控板、数字键盘、播放控制和游戏手柄；当前项用文字“当前”标识。四种遥控类型不再进入功能网格。类型页返回选择页、选择页返回标准遥控器，设备页仍返回原页面；旋转保留页面与草稿。

游戏手柄横屏内容可扩展至 960dp，页面外边距使用 8dp，主操作区不重复页面标题，保证普通横屏下 SELECT/START 可见。主操作区左侧圆形摇杆、右侧 Y/X/B/A 菱形圆键，右摇杆与原有肩键/方向帽保留，SELECT/START 居中。使用现有中性色和功能绿，不复制参考图的多色和重阴影。主键 56dp、菱形区 176dp，摇杆 132dp、摇杆触点直径 44dp，左右区至少 400dp 才并排，至少 520dp 时将右摇杆也放入同一主操作行，以保留多指同时操作；短屏允许纵向滚动，管理与说明不能挤占主操作区。


## 文件与应用管理

两页采用列表优先的信息结构：16dp 外边距、白色连续列表、0.5dp 分隔线，40dp 文件/应用图标，行标题17sp、次行14sp、类型12sp，最小72dp 行高；按钮和更多菜单至少48dp。共享代码矢量图标统一24×24、1.7线宽，不增加装饰色。文件夹/应用用功能绿，危险菜单项用 Warning。搜索框、分类控件和排序属于页面工具，不是主导航。

应用页展示总量与刷新、搜索和全部/用户/系统筛选；默认每次30项，搜索匹配全量缓存。点击条目查看操作，右侧提供启动与更多；详情、清理缓存、卸载按需进入管理对话框。按包名打开与模型待确认任务放在页内工具入口，列表不再逐项堆叠按钮，不默认展示原始执行结果。

文件页提供根范围、可点击祖先路径、上一级、刷新、新建目录和操作/传输入口；文件夹优先，当前已加载条目可搜索、按名称或文件大小排序，分页未完明确显示“仅搜索已加载项目”。点击文件夹进入，文件默认查看属性，更多菜单提供下载/媒体/APK/删除；符号链接和特殊文件只说明不可访问，不提供删除或进入。新建目录使用对话框，目录草稿按根和路径保存；传输、媒体、存储分析与APK安装按需打开同一可滚动操作对话框，关闭不自动取消任务，有任务状态入口可重新打开。路径、搜索和筛选变化只调整展示，不能改变服务游标或扩大文件权限。

管理对话框最大宽560dp、最大高640dp，标题与48dp关闭按钮固定，正文独立滚动。离线、读取中和不支持能力分别反馈；首次加载、空目录、无搜索结果、出错与已有缓存分别区分，重试保留可读列表。删除、覆盖、卸载、缓存清理和安装沿用服务确认对象及不可恢复影响，确认内容可滚动；不把点开菜单当作提交。

文件操作窗口以传输、媒体、APK 安装和存储分析四个页内选项按需展示，关闭窗口保留非敏感表单草稿和后台任务；页面显示等待确认、任务进行、可保存、错误或已有结果入口。目录大小使用二进制 KiB/MiB/GiB，属性同时保留精确字节。刷新失败保留已有列表，文件排序不修改分页游标；路径点击仅允许当前根内的祖先目录。

在线首次进入应用页或尚未加载的文件范围时自动读取，已有列表不重复读取；错误后由用户显式重试，不自动循环请求。

文件路径栏将上一级图标、可换行的祖先路径与新建目录放在同一行；当前路径使用正文色，不以禁用灰弱化位置信息。分类控件换行后保留4dp行间距。

## 表单可用性与稳定布局

- 开关与勾选项以整行作为唯一可切换区域，至少 56dp 高，合并说明与选中语义；标签允许换行，开关/勾选图形本身不重复接收点击。
- 提交依赖连接、模型或接口支持时，在动作附近说明缺少的条件。已填入的无效数值提供具体校验说明，不让用户猜测禁用原因。
- 顶部全局进度叠放在内容边缘，不因开始或结束任务改变页面可用高度。三列网格同一行的点击背景等高，标签随字体换行。
- 系统操作、媒体副本及设备名称确认的正文可独立滚动，确认与取消保持可见；媒体来源选项在窄屏自动换行。
- 文字编辑页保留简明提交状态和折叠操作详情，完整原始输出通过执行结果入口阅读。

遥控器、触控板、数字键盘、播放控制与手柄的频繁动作使用页内状态反馈，不逐次弹出全局完成提示以遮挡底部控件；错误仍明确提示，收到响应不等同于目标实际操作成功。
