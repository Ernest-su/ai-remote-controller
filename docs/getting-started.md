# 快速开始

## 准备

准备一台控制手机和一台可通过 ADB 访问的目标 Android 设备，两者连接可互通的局域网。控制手机无需开启本机无线调试；产品不使用 USB 连接。无线配对取决于目标系统支持，未提供该功能的目标可使用已经启用的 TCP ADB。

控制端最低支持 Android 8.0 / API 26；目标 runtime 提供 ARM64、ARMv7、x86_64 三种 ABI。普通按键无需模型，AI 文字任务需要目标可访问的兼容模型接口。

## 获取与安装

维护者公开的生产签名 APK 位于 [GitHub Releases](https://github.com/Ernest-su/ai-remote-controller/releases)。若尚无公开版本，可从源码构建：

```sh
export ANDROID_HOME=/path/to/android-sdk
export ANDROID_NDK_HOME="$ANDROID_HOME/ndk/28.2.13676358"
./gradlew :androidApp:assembleDebug --no-daemon
```

开发机需要 JDK 17、Android SDK 36、NDK `28.2.13676358`、Rust/Cargo/rustup 和 Python 3.11+；Gradle daemon 按仓库配置使用 JetBrains JDK 25，首次自动获取。构建会将三 ABI runtime 打包到 APK，无需单独安装目标程序。详细环境见[从源码构建](development/build.md)。

Windows 原生构建及 Python 解释器设置见[构建文档](development/build.md)。

debug APK 输出为 `androidApp/build/outputs/apk/debug/androidApp-debug.apk`，安装到控制手机。debug 与生产 APK 使用不同证书，不能互相直接覆盖安装；如需切换，应在卸载前确认能够重新配置模型与设备信息。

生产签名、六项 GitHub Secrets 和草稿 Release 的使用方法见[签名与发布](development/releasing.md)。只有公开的 Release 才能进入 App 在线更新入口。

## 首次连接

1. 在目标设备开启适用的 ADB 连接方式，并准备完成目标上的授权。
2. 打开绿色电视与 AI 遥控器图标的「AI 遥控」，首页始终为遥控器。
3. 点击右上角连接状态进入设备页。附近、历史与局域网服务合并显示；可选择已有设备连接，或展开「连接目标设备」填写 TCP、配对码或二维码信息。
4. 已发现设备的服务连接失败时，应用自动尝试 ADB 部署（未保存端口时使用 `5555`）并提示；失败后展开手动连接并填入目标 IP，可修改端口或切换配对方式。保持目标在线，等待校验、推送与启动完成。配对端口和连接端口不同，具体步骤见[连接设备](guide/connections.md)。
5. 设备页顶部显示连接进度与结果，无额外完成弹条；显示「已连接」后，试用方向、确认、返回、主页或音量。按键和应用启动无需模型。

连接时会传递 App 语言，设备能力和权限错误按中文或英文显示；更改语言后重新连接生效。

快速连按提示操作队列已满时，等待已有操作完成后再重试；服务会保留连接和已接受的操作，不自动重试被拒绝的按键。

标准遥控与数字键盘支持真实按住：按下立即发送、松开释放，长按重复由目标 Android 处理；例如按住方向连续移动、按住菜单向目标应用发送长按。切页、后台或断线会取消按住。

普通按键使用独立遥控通道和预热输入桥接，不受媒体查询或文件操作排队影响。若提示按键结果不确定，请先核对目标状态；服务仅尝试释放按键，不会自动重复按下。

连接时自动核对被控服务的版本与二进制摘要，不匹配时通过 ADB 更新配套程序并重新连接，保留现有配置；ADB 未授权或更新失败时不会继续使用旧服务。版本与摘要均匹配时直接复用连接。

目标程序默认安装到 `/data/local/tmp/airc/airc-runtime`，服务端口默认 `9876`，默认以 ADB shell 身份运行。在「功能 → 运行权限」可选择优先 root；只在目标已支持并授权时使用，不为目标获取 root。

若部署提示端口被占用，请先核实并停止占用进程，再重试；残留 root 服务需要 root 权限停止。不要删除程序或状态目录来代替停止服务。处理方法见[设备端服务与更新](guide/services.md)。

协议不提供用户登录鉴权，请在可信局域网使用。删除、卸载、缓存清理、安装和系统管理使用各自确认流程；普通遥控和文字任务不会逐步确认。

玩 NES 游戏时，从右上角遥控器类型进入「游戏手柄」，在标题旁选择「NES 经典手柄」，再点击播放图标开始；大十字键与圆形 A/B 支持同时按住，尺寸和排列随屏幕调整。需要模拟摇杆时选择「双摇杆手柄」，布局和映射自动切换。详见[游戏手柄](guide/gamepad.md)。

## 手机日常操作

“电视输入”可在剪贴板粘贴和输入法提交之间切换，并按电视记住选择。首次使用输入法提交时，点击“安装并启用”安装配套 AIRC 电视输入法，再在电视选中输入框发送；它不改电视剪贴板。需要时点击“恢复电视原输入法”。两种方式都需要可用的 ADB，失败后核对内容再手动重试。详见[电视输入](guide/remote.md)。

标准遥控器右上角三点菜单以带图标的竖排列表提供“常用应用”“电视输入”和“快捷操作”。常用应用支持搜索、筛选系统/用户应用，点行尾星标收藏，收藏项优先显示，可按电视调整顺序；电视输入无需模型，先选中电视输入框，再用手机输入中文或显式粘贴，发送后核对电视内容。文字通过已授权 ADB 写入电视剪贴板，目标应用需允许粘贴，不记录输入历史。

“快捷操作”点加号新建，从列表选应用、网格选按键或按秒设置等待；步骤可编辑、排序、复制和移除。保存后点列表运行按钮直接执行，可在原位暂停/继续；通过更多菜单查看最后一次执行详情，失败或停止后不继续后续步骤。设置中可启用手机音量键控制电视、遥控保持亮屏；触控板可选择滑动方向、点按确认的手势模式。播放控制支持时间进度条、前后 10/30 秒和按分:秒跳转，是否可定位取决于播放器。

从手机浏览器、相册或文件管理器选择系统分享中的“AI 遥控”，可以将网址填入电视下载表单、文字填入电视输入或上传单个文件，内容不会自动执行。设备页分别查看遥控、管理 ADB 和预览连接，并按需恢复。

## 第一个 AI 任务

1. 左上角菜单进入三列功能网格，打开「模型配置」。
2. 填写 API 根地址、API Key 与模型名称，点击「保存到 App」。模型列表可手填，也可手动拉取并缓存。
3. 连接目标后点击「更新到目标设备」。本地保存不会自动同步，目标必须能访问对应提供商。
4. 目标未配置模型时，标准遥控器底部只显示不可点击的配置提示，隐藏输入框与发送按钮。更新到目标设备成功后，回到遥控器底部输入任务，点击发送图标或键盘发送键；较长任务可在「文字指令」页编辑。
5. 查看执行反馈并核对目标实际行为，完整输出从「执行结果」进入。

启用 AIRC 电视输入法后，电视文字框获得焦点时，遥控与预览页会显示“输入文字”，点击打开手机输入面板与键盘；不会自动发送。目标未配置模型时，遥控器底部以小字号单行提示配置入口。空白、离线、目标未配置模型或已有文字请求进行中时禁止发送。草稿在导航与旋转后保留，只在请求被接受后清空。反馈每次更新后显示五秒，再回到播放状态；切页或旋转不会重新显示已过期反馈。更多说明见[遥控与文字指令](guide/remote.md)和[模型配置](guide/models.md)。

## 常用入口

| 入口 | 用途 |
| --- | --- |
| 右上角连接状态 | 设备连接、显示名、断开与网络诊断 |
| 右上角遥控器类型 | 标准遥控器、触控板、数字键盘、播放控制与游戏手柄 |
| 功能 → 应用管理 | 搜索、启动、应用信息及确认后的缓存清理/卸载 |
| 功能 → 设备预览 | [截图保存、分享与动态预览](guide/screenshots.md) |
| 功能 → 文件管理 | [浏览、上传、下载、目录、APK 与存储分析](guide/files.md)；符号链接支持范围内只读浏览、预览和下载 |
| 文件管理 → 媒体 | [目标播放器、HTTP 媒体流与本地播放副本](guide/media.md) |
| 功能 → 设备信息 | 只读系统与硬件信息、[电源观察与系统管理](guide/system.md) |
| 功能 → 设置 | 跟随系统、亮色或暗色，以及遥控按键震动开关（点按短震、长按弱震、松开或取消即停，同键重复按下会清理旧计时，快速连按不延续长按反馈），离线可修改并本地保存 |
| 功能 → 服务管理 | [查询、更新、重启和停止服务](guide/services.md)，需要已保存的 ADB 连接 |

功能子页返回功能菜单，菜单返回遥控器；设备页返回来源页。短窗口、大字体或键盘展开时，遥控按键区域可以滚动，底部文字输入入口保留。

桌面联调可从项目目录运行 `./gradlew :desktopApp:run --no-daemon`，使用宿主机 adb；操作与限制见[桌面指南](guide/desktop.md)。遇到问题先阅读[故障排查](troubleshooting.md)。

Android 进入“设备预览”后自动开启动态预览，可选择流畅、均衡或清晰档位（最长边上限分别为720、1280、1920像素），切换后自动重启视频流，预览区域保持等比显示，悬浮遥控默认紧凑布局，右上角关闭图标左侧可切换完整布局；按住左上角四向箭头手柄直接拖动可调整位置，其他位置可长按后拖动，靠近边缘松手可吸附；在设置的“悬浮遥控”分组调节透明度（60%–90%，默认60%），闲置5秒自动淡化，触摸恢复；可直接触摸操作目标，通过动态预览标题右端的全屏图标放大画面，左侧遥控器图标可在普通或全屏模式展开悬浮遥控；全屏工具栏和悬浮遥控使用透明外框、局部半透明按键衬底，让画面透出并保留按钮可见性；低延迟解码仅在控制端支持时启用；两种模式均保持原比例，切换后持续或自动恢复预览；返回前台和旋转后自动恢复，不再提供开始、停止按钮。详见[设备预览与动态预览](guide/screenshots.md#screen-mirror)。

“文件管理”的操作集中在底部图标栏，放不下的操作从右侧三点菜单展开；提供列表/网格、图片与媒体缩略图、文本摘要、目录内搜索与分类和长按选择，弹窗只展示当前操作。网址下载粘贴地址后自动识别文件名和大小，名称仍可修改；点击文件可预览，音视频明确选择在主控设备或被控设备播放，APK 支持真实图标、信息预览及在被控设备安装；上传及删除沿用独立确认与任务进度。详见[目标文件管理](guide/files.md)。

游戏手柄在 root 与非 root 下使用相同的左右摇杆、X/Y/A/B、SELECT/START 布局，连接后点击“游戏手柄”标题旁的播放图标开始，同一图标可停止；操作区固定，不支持横向或纵向滚动。手柄请求超时会清空输入并在原连接内快速自动重连，最多连续重试三次；点击标题图标可中止重连。root/uinput 可用时创建虚拟设备，非 root 使用重复短时合成输入，连续性与游戏兼容性有限。详见[游戏手柄](guide/gamepad.md)。

Android App 打开后自动尝试连接最后一次成功连接的设备；意外断连后按 3、6、12、24 秒递增重试，之后每 30 秒重试。手动取消连接、断开或停止服务后暂停自动重连；主动连接其他设备会切换目标。自动连接仍核对配套版本，必要时通过已保存的 ADB 方式部署，不重放遥控按键或文字任务。

应用管理的图标在滚动返回时复用当前连接缓存；刷新时保留安装与资源标识未变化的图标，切换连接后重新读取。

应用、文件与设备信息页不再展示模型待确认提案的分散查询入口。卸载、缓存清理、删除、安装与系统操作从具体目标的手动操作开始，仍须核对原有确认弹窗。

应用管理点击应用行或更多菜单中的“应用详情”进入同一个[应用详情页](guide/apps.md)，可查看权限并按目标支持情况管理授权、强行停止、停用/启用、清理缓存、清除全部数据及卸载。权限列表优先显示可操作的开关。修改需逐项确认，成功后自动刷新目标状态；系统及特权应用仅供查看，离线禁用实际操作。

## 常用扩展入口

连接后可在「功能 → 定时操作」创建被控端任务，选择15/30/60/90分钟或1/2/3小时倒计时，也可选择未来单次时间或每天固定时间，执行暂停、调节媒体音量（0–100%）、静音、解除静音、关机或应用操作。任务保存在被控端，手机退出不影响执行；每天任务需要被控设备开机后启动遥控服务，详见[运行条件](guide/schedules.md#daily-requirements)。

网址下载遇到同名文件时，可使用建议的新名称，或核对文件后确认覆盖。

上传时可随时选择本地文件，已有下载待保存时仍保留选择草稿，处理原任务后再开始上传。文件管理支持在列表或网格中「多选」，勾选最多32个普通文件后，先选择「打包为 ZIP」或「逐个下载」，确认才开始；逐个下载可选择文件夹，分别保存原文件。

文件管理的任务提示可用右侧关闭图标隐藏，出现新任务才重新显示；同一行的图标加「查看」可打开详情。

「定时操作」通过下拉列表选择倒计时与执行动作，单次或每天任务通过时间选择器设置；单次自动安排到未来最近一次所选时间，无须选择日期。

「文字指令 → 看图操作」会读取画面交给模型，选定时显示说明，不增加读取许可开关。快捷操作的添加步骤页通过带图标的下拉列表选择类型，支持「等待应用进入前台」「等待播放开始」等条件等待；手机桌面可添加应用或组合入口及小组件，添加前可修改默认名称并选择图标。「设置」可为每台电视配置额外遥控按键，「文件管理 → 上传文件」可选择一个或多个文件，下载通过列表「多选」进入，「文件任务」统一查看进度、手动续传与保存结果。详见[遥控指南](guide/remote.md)和[文件管理](guide/files.md#batch-transfers)。

被控端 Downloads 不支持原子“不覆盖”提交时，单文件和多文件上传会自动使用校验后的复制保存，同名文件保留；保存期间请等待任务完成，需预留额外一份文件的空间。

文件管理的“存储分析”可查看文件总大小、类型占比和较大文件，列表内可核对并确认删除；删除后重新分析更新统计。“文件任务”按类型分类，标签显示任务数量，0项分类不可点击。

文件管理支持将 `.aac` 音频交给被控端播放器播放，包括 Downloads 文件与服务收件箱中的本地播放副本。
