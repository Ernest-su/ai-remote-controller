# 快速开始

## 准备

准备一台控制手机和一台可通过 ADB 访问的目标 Android 设备，连接可互通的局域网。控制手机无需开启本机无线调试；产品不使用 USB 连接。目标上的无线配对功能取决于系统支持，未提供该功能的目标可使用已经启用的 TCP ADB。

当前从源码构建 APK。开发机需要 JDK 17、Android SDK 36、Android NDK、Rust/Cargo/rustup、Python 3。已验证 NDK `28.2.13676358` 与 Linux x86_64 构建环境；其他主机环境尚未完整验证。

```sh
export ANDROID_HOME=/path/to/android-sdk
export ANDROID_NDK_HOME="$ANDROID_HOME/ndk/28.2.13676358"
./gradlew :androidApp:assembleDebug --no-daemon
```

Gradle 会构建设备端三 ABI 资产并打包到 APK。首次构建需要网络下载依赖。把 `androidApp/build/outputs/apk/debug/androidApp-debug.apk` 安装到控制手机。更多构建说明见[开发构建](development/build.md)。

## 选择外观

打开「功能 → 设置 → 外观」选择「跟随系统」「亮色」或「暗色」。默认跟随系统；选择立即生效并保存在当前手机，离线也可使用。桌面工具在同一入口设置，独立保存。

## 首次连接

安装后，点击带有电视与 AI 遥控器图案的绿色「AI 遥控」应用图标，进入遥控器首页。

1. 在目标设备开启适用的 ADB 连接方式。
2. 点击控制手机右上角的连接状态，进入“设备”页，选择 TCP、配对码或二维码；详细步骤见[连接设备](guide/connections.md)。
3. 保持目标设备在线，等待程序校验、推送和启动完成。旧版 ADB 的部署脚本通过文件传输，避免长命令超出单包限制。
4. 应用显示已连接后，试用方向键与音量，或在左上角功能网格中打开“应用管理”；这些操作无需模型。

目标程序默认安装到 `/data/local/tmp/airc/airc-runtime`，默认以 ADB shell 身份运行；可在功能网格的“运行权限”开启[优先 root 权限](guide/connections.md)，服务端口默认 `9876`。设备页自动扫描当前 Wi-Fi 同网段 ADB，历史与局域网发现结果合并在一个列表，可直接点击连接。

## 第一个 AI 任务

文字指令页会说明连接、模型配置或请求进行中的发送限制；输入草稿在导航与旋转后保留。提交后可展开「查看操作详情」，或从功能菜单进入「执行结果」阅读完整反馈。

从左上角功能网格进入“模型配置”，配置[兼容模型接口](guide/models.md)。回到遥控器底部输入文字任务，点击发送图标；也可在“文字指令”页编辑。查看执行结果并确认目标实际行为。

当前没有用户登录或执行前确认机制，请在可信局域网使用。遇到问题见[故障排查](troubleshooting.md)。

设备页将已保存、局域网服务与扫描到的 ADB 合并在同一列表，手动连接默认折叠。遥控器首页的弹性状态区切换显示执行反馈与播放状态，并提供媒体播放和静音按键；功能菜单取消独立媒体控制入口。

遥控器尺寸与排列参考 phoneRemoteApp；状态更新后优先显示反馈，五秒无更新自动回到播放。新版目标服务支持请求关联的思考/工具调用进度，旧版保留最终结果回退。

文字输入框在键盘上方固定显示，上方遥控按键可滚动；键盘收起后恢复普通布局并保留草稿。

设备端新增只读 `device.info` 工具，可通过 WebSocket 或模型查询系统与硬件摘要，详见[工具参考](reference/tools.md#device-info)。在功能菜单的「设备信息」页点击「刷新设备信息」查看。

应用管理现在支持刷新目标应用列表、搜索包名和点击启动，模型也通过同一个 `apps.list` 工具获取结构化结果。名称由目标包管理器读取，不可用时保留包名。

目标二进制服务新增受控点击、滑动、长按和数字/频道按键工具，支持直接请求与模型调用；在遥控器右上角的类型选择页进入「触控板」或「数字键盘」使用。

模型配置支持按 API 地址保存多套本地配置、切换与删除，API Key 可显示/隐藏。填好地址和 Key 后手动拉取并缓存模型列表，模型可手填或从列表选择。连接目标后点击「更新到目标设备」，详见[模型配置](guide/models.md)。

开发联调也可运行 `./gradlew --no-daemon :desktopApp:run` 使用手机比例的 Compose 桌面工具，通过宿主机 adb 连接、部署目标并测试工具与模型配置。后续测试优先在 JVM 执行，见[桌面指南](guide/desktop.md)。

连接成功后，可在设备页修改本应用中的设备显示名；再次连接仍保留该名称。

遥控器播放区域会显示目标 MediaSession 的真实状态。没有活跃播放器时显示“暂无媒体播放”；可在遥控器类型的「播放控制」中查看时长并按毫秒定位。

新版服务支持功能菜单中的“设备截图”：手动获取目标画面后可预览和保存 PNG；手机还可通过系统分享面板分享。

连接失败时可在设备页运行“诊断服务连接”，查看 HTTP、WebSocket、ADB 和发现阶段的实际结果与处理建议。

功能菜单的“目标文件”支持 Downloads、服务收件箱与确认后的全盘浏览，可上传、下载、查看属性、确认覆盖和删除。大文件使用流式传输及 SHA-256 校验，摘要准备和传输阶段均可取消；默认禁止覆盖，权限沿用目标服务身份。操作方法见[目标文件](guide/files.md)。

上传图片、音乐或视频后，可在目标文件条目点击“媒体打开”，查询支持的目标播放器并手动启动，详见[媒体投送](guide/media.md)。

若目标预装播放器不能读取私有目录的 HTTP 媒体流，可选择“本地播放副本”，确认 Downloads 的可读范围与空间后创建、校验并打开，播放后释放副本。原文件保留。

服务重启后可在目标文件媒体分组点击“查看保留的播放副本”，按路径和大小逐项释放。恢复记录不会自动播放，原文件保留。

媒体打开后需要核对目标实际播放。播放器声明支持 MIME 不等于解码成功，当前目标部分预装播放器存在兼容性问题；可选择其他支持该来源和格式的播放器。

应用管理可查询应用版本并卸载用户应用；卸载需核对包名、版本、Android 用户并确认删除应用数据。系统与特权应用不提供卸载。

目标文件中的 APK 可查看包名、版本、SHA-256 和声明证书指纹；信息解析不执行安装，也不证明签名有效。

APK 信息核对后可准备单 APK 安装；覆盖安装须显式勾选，并在第二步确认包名、版本、用户、摘要与跨用户影响。确认后由目标包管理器验证安装，提交阶段不可取消。

目标文件页的“分析此目录”可只读查看文件类型统计和大文件列表，支持进度与取消；统计不是可回收空间，不会自动清除应用数据。

遥控器类型选择页中的“播放控制”可读取标准会话位置/时长，按毫秒提交定位并查询结果；只在目标接口与播放器都支持时启用。

应用管理列表可按目标的真实应用名称或包名搜索；名称不可读取时保留包名，刷新可重新查询。

“播放控制”刷新并选中活动播放器后，还可调用播放器明确声明的自定义动作。仅展示声明名称；没有动作的播放器不显示选集或清晰度按钮。提交后核对目标结果。

遥控器类型选择页提供“游戏手柄”输入原型，可发送有限时长按钮组合及 X/Y 摇杆值，结束后自动释放并回中。合成来源不保证游戏支持，操作见[游戏手柄](guide/gamepad.md)。

应用管理支持独立确认后的[仅清理缓存](guide/cache.md)。先核对包名和 Android 用户；旧系统不支持 cache-only 时拒绝，不会改为删除应用数据。

目标使用 Toybox/UID 形式 su 时，部署可探测 `su 0 sh -c`；用户关闭 root 偏好时仍运行 shell。已有服务的权限切换与失败回滚会保留设备身份及状态。

持续手柄需要 root/uinput，在[手柄页](guide/gamepad.md)手动开始后按住按钮或拖动左右摇杆；离页和断线停止。

系统管理：在功能菜单的“设备信息”页准备锁屏、重启或关机，核对目标后显式确认；需要 root 和框架权限，提交或断线不代表动作已完成，详见[系统管理](guide/system.md)。

在“设备信息”点击“刷新电源与锁屏状态”可读取只读观察；未知值显示未知，观察结果不代表此前系统操作已经完成。

支持 files.mkdir 的服务可在目标文件页输入新目录名称并点击“创建目录”，也可通过模型任务调用；已有同名条目不会覆盖。

可在「功能 → 设置 → 外观」选择跟随系统、亮色或暗色。默认跟随系统，立即生效并保存；切换不会清空文字草稿，状态栏与导航栏图标随主题调整。

手机手柄模式自动使用横屏，离开该页恢复原方向策略。

触控板会适配横屏和短窗口，完整显示触控区并映射目标完整屏幕。

Android 动态预览已接入 ascrcpy：先通过设备页保存目标 ADB 连接，再进入截图页开始镜像。退出或后台会停止，返回需手动开始。JVM 只提供单张截图、刷新和保存，不实现动态预览，详见[截图与镜像](guide/screenshots.md)。


Android 动态画面统一由 ascrcpy 提供，旧 PNG 连续预览入口已移除；动态预览期间需先停止，再获取单张截图。


Android 动态预览结束后清除最后一帧，保留失败提示并允许手动重试。

进行真实模型只读验收时，使用支持请求级工具范围的新服务和配套验收入口；仅在提示词里写“只读”不足以限制工具执行。

覆盖推送大文件时，App 先扫描源文件摘要，再请求覆盖确认；确认后开始传输。扫描期间可取消，详见[目标文件](guide/files.md)。

手机手柄页自动横屏；持续手柄采用左摇杆与右侧菱形 A/B/X/Y 分区，保留右摇杆和全部扩展按键。退到后台会停止输入，返回后手动开始，见[游戏手柄](guide/gamepad.md)。

模型配置保存或列表缓存写入期间仍可编辑模型名称，操作完成后保留新草稿；保存后新编辑的名称需再次保存，见[模型配置](guide/models.md)。

递归删除限定在用户选定目录的文件系统内，不跨入其他挂载点；遇到边界会报告错误，已删除项不能恢复。

同步模型配置期间不要切换连接；重连后需重新点击“更新到目标设备”，旧操作不会将密钥发到新连接。

存储分析取消后，请等待忙碌状态结束再重新分析；取消期间不会删除源文件。

缓存清理遇到任务对象不匹配时请核对目标状态；界面不会将该响应当作清理完成。

应用安装或卸载若报告任务对象不匹配，请刷新应用信息核对目标状态；该响应不会被当作完成。

APK 安装完成提示同时核对已确认的用户与文件 SHA-256；遇到结果不匹配时，请通过应用信息核对目标实际状态。

媒体投送若遇到播放副本任务不匹配，可通过保留副本列表核对资源；界面不会根据错配响应打开或释放其他副本。

媒体资源释放未获目标确认时，控制端保留记录；可核对目标后重试释放。

投送会核对目标响应是否对应所选播放器及文件格式；启动提示仍需结合目标画面确认播放。

界面修改优先使用 JVM 与独立 Android 模拟器验证；运行方法见[模拟器测试](development/testing.md#emulator-controller)。真机专项按平台与硬件需求选择。

媒体副本准备会核对来源文件和完整进度；错配结果不会用于播放，可核对源文件后重试。

新构建中的模型 Shell 仅允许只读诊断；文字输入改走结构化 remote.text，支持 ASCII，目标输入法可能改写内容。使用新版 App 手动更新二进制后生效，原服务不会由测试自动替换。

当前二进制提供受控界面层级查询，供模型读取 UI 信息；不需恢复任意 Shell。更新二进制后可用，捕获结果不是原子快照。

截图或文件浏览请求取消后可重试。若取消的是新建目录，先刷新确认目标现状，再决定是否重试。

手柄有限输入若报告连接变更或释放未确认，重新连接后核对目标状态再操作。

文件列表响应异常时保留原缓存，先刷新重试再选择文件操作。

文件属性提示响应不匹配时，刷新目标目录再查询，避免沿用已变化条目的属性。

媒体副本恢复提示描述异常时，重新读取保留副本后再释放；不要将异常列表视为成功恢复。

文件分页游标异常时，重新刷新目录后再继续浏览。

目录分页提示顺序异常时重新刷新；浏览过程中目标目录发生变化也应刷新核对。

查询文件属性时旧属性会清除，失败后重新选择条目查询。

媒体候选响应异常时重新读取，不使用此前文件的播放器选择。

切换设备后重新查询应用列表再启动；此前排队的应用请求不会转发到新目标。

切换目标后重新发起按键或手势，原排队动作会因连接变化被拒绝。

切换目标后重新提交文字任务；连接校验未接收的提交保留草稿。

设备连接变化后旧执行反馈会丢弃，当前提示保持独立。

切换设备后重新刷新设备信息，旧查询不会转发到新连接。

桌面端快速重连后媒体状态轮询自动切换到新会话，显示实际报告状态。

切换或重连后两端媒体状态会按新会话重新查询。

电源键由用户在遥控器上直接操作；模型系统动作需在 App 确认提案。

动态预览支持目标视频尺寸变化后的解码重配；手机切后台或旋转后仍需重新开始。


应用管理按需加载应用图标，先显示 30 项，可搜索完整列表或继续展开。快速滚动会取消离屏图标的后续下载，刷新后丢弃旧请求；图标失败不影响列表与启动。安装分包应用时，先上传 base 和所需 split APK，在目标文件页逐个查看 APK 信息并“加入多包安装”，核对整组后准备、确认安装；详见[多包安装](guide/files.md#split-apk)。

文件与应用管理采用列表浏览：应用可搜索、筛选并从行尾快捷启动；文件可点击文件夹和祖先路径导航，搜索当前已加载目录、按名称或大小排序。条目更多菜单提供管理操作，文件右上角操作与任务入口集中传输、媒体、APK 安装和存储分析；关闭窗口后可从状态入口返回任务。详见[应用管理](guide/remote.md#applications)与[目标文件](guide/files.md)。
