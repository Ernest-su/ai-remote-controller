# 快速开始

## 准备

准备一台控制手机和一台可通过 ADB 访问的目标 Android 设备，两者连接可互通的局域网。控制手机无需开启本机无线调试；产品不使用 USB 连接。无线配对取决于目标系统支持，未提供该功能的目标可使用已经启用的 TCP ADB。

控制端最低支持 Android 8.0 / API 26；目标 runtime 提供 ARM64、ARMv7、x86_64 三种 ABI。普通按键无需模型，AI 文字任务需要目标可访问的兼容模型接口。

## 获取与安装

维护者公开的生产签名 APK 位于 [GitHub Releases](https://github.com/Ernest-su/ai-remote-controller/releases)。若尚无公开版本，可从源码构建：

```sh
export ANDROID_HOME=/path/to/android-sdk
export ANDROID_NDK_HOME="$ANDROID_HOME/ndk/28.2.13676358"
./gradlew :androidApp:assembleDebug --no-daemon
```

开发机需要 JDK 17、Android SDK 36、NDK `28.2.13676358`、Rust/Cargo/rustup 和 Python 3.11+；Gradle daemon 按仓库配置使用 JetBrains JDK 25，首次自动获取。构建会将三 ABI runtime 打包到 APK，无需单独安装目标程序。详细环境见[从源码构建](development/build.md)。

debug APK 输出为 `androidApp/build/outputs/apk/debug/androidApp-debug.apk`，安装到控制手机。debug 与生产 APK 使用不同证书，不能互相直接覆盖安装；如需切换，应在卸载前确认能够重新配置模型与设备信息。

生产签名、六项 GitHub Secrets 和草稿 Release 的使用方法见[签名与发布](development/releasing.md)。只有公开的 Release 才能进入 App 在线更新入口。

## 首次连接

1. 在目标设备开启适用的 ADB 连接方式，并准备完成目标上的授权。
2. 打开绿色电视与 AI 遥控器图标的「AI 遥控」，首页始终为遥控器。
3. 点击右上角连接状态进入设备页。附近、历史与局域网服务合并显示；可选择已有设备连接，或展开「连接目标设备」填写 TCP、配对码或二维码信息。
4. 已发现设备的服务连接失败时，应用自动尝试 ADB 部署（未保存端口时使用 `5555`）并提示；失败后展开手动连接并填入目标 IP，可修改端口或切换配对方式。保持目标在线，等待校验、推送与启动完成。配对端口和连接端口不同，具体步骤见[连接设备](guide/connections.md)。
5. 显示「已连接」后，试用方向、确认、返回、主页或音量。按键和应用启动无需模型。

目标程序默认安装到 `/data/local/tmp/airc/airc-runtime`，服务端口默认 `9876`，默认以 ADB shell 身份运行。在「功能 → 运行权限」可选择优先 root；只在目标已支持并授权时使用，不为目标获取 root。

协议不提供用户登录鉴权，请在可信局域网使用。删除、卸载、缓存清理、安装和系统管理使用各自确认流程；普通遥控和文字任务不会逐步确认。

## 第一个 AI 任务

1. 左上角菜单进入三列功能网格，打开「模型配置」。
2. 填写 API 根地址、API Key 与模型名称，点击「保存到 App」。模型列表可手填，也可手动拉取并缓存。
3. 连接目标后点击「更新到目标设备」。本地保存不会自动同步，目标必须能访问对应提供商。
4. 回到遥控器底部输入任务，点击发送图标或键盘发送键；较长任务可在「文字指令」页编辑。
5. 查看执行反馈并核对目标实际行为，完整输出从「执行结果」进入。

空白、离线、目标未配置模型或已有文字请求进行中时禁止发送。草稿在导航与旋转后保留，只在请求被接受后清空。反馈每次更新后显示五秒，再回到播放状态；切页或旋转不会重新显示已过期反馈。更多说明见[遥控与文字指令](guide/remote.md)和[模型配置](guide/models.md)。

## 常用入口

| 入口 | 用途 |
| --- | --- |
| 右上角连接状态 | 设备连接、显示名、断开与网络诊断 |
| 右上角遥控器类型 | 标准遥控器、触控板、数字键盘、播放控制与游戏手柄 |
| 功能 → 应用管理 | 搜索、启动、应用信息及确认后的缓存清理/卸载 |
| 功能 → 设备截图 | [截图保存、分享与动态预览](guide/screenshots.md) |
| 功能 → 目标文件 | [浏览、上传、下载、目录、APK 与存储分析](guide/files.md) |
| 目标文件 → 媒体 | [目标播放器、HTTP 媒体流与本地播放副本](guide/media.md) |
| 功能 → 设备信息 | 只读系统与硬件信息、[电源观察与系统管理](guide/system.md) |
| 功能 → 设置 | 跟随系统、亮色或暗色，以及遥控按键震动开关，离线可修改并本地保存 |
| 功能 → 服务管理 | [查询、更新、重启和停止服务](guide/services.md)，需要已保存的 ADB 连接 |

功能子页返回功能菜单，菜单返回遥控器；设备页返回来源页。短窗口、大字体或键盘展开时，遥控按键区域可以滚动，底部文字输入入口保留。

桌面联调可从项目目录运行 `./gradlew :desktopApp:run --no-daemon`，使用宿主机 adb；操作与限制见[桌面指南](guide/desktop.md)。遇到问题先阅读[故障排查](troubleshooting.md)。
