# 文件管理

从遥控器的三列功能菜单打开“文件管理”。手机与 JVM 桌面共享文件管理界面；连接新版服务后可浏览目录、查看属性、上传、下载、覆盖文件，以及删除文件或目录。


## 符号链接

目录链接可以进入，文件链接可查看属性、在主控端预览或下载，始终受当前 Downloads、服务收件箱或全盘范围限制。范围内的相对链接、绝对链接和多级链接均可跟随；链接解析最多40层。目标超出 Downloads 或收件箱时显示越界原因，不自动切换全盘。全盘浏览仍受服务实际权限限制，进程文件描述符等特殊链接不可访问；链接目标不存在、循环或无权限会分别提示。

进入链接目录后，路径栏保留原浏览路径，返回回到原父目录；页面提示只读。该目录下的上传、覆盖、新建目录、删除、安装/被控播放入口与递归扫描不可用，也不能选为网址下载的保存目录。需要写入时，应通过真实目录路径进入。普通链接仅开放读取，选择“删除链接”仍需确认，且只移除链接本身。预览和下载固定已打开的文件，链接随后改指向其他位置不会改变本次读取来源。

## 浏览范围

默认打开 Downloads。可切换“服务收件箱”，它位于服务状态目录下的 `files/`，适合大文件推送。“全盘 /”需要先确认，然后从目标文件系统根目录浏览。访问权限由服务当前 shell/root 身份决定，进入全盘不会自动提权；无权限的目录会显示错误。

在线首次进入页面或切换范围时自动读取，底部刷新图标可重新读取列表，每页 50 项。点击文件夹进入，点击祖先路径或“上一级”返回；点击图片、音视频或文本进入主控端预览，点击 APK 读取信息并选择在被控设备安装；其他普通文件查看属性，所有文件均可从更多菜单查看属性。大小同时显示易读单位与精确字节。列表默认文件夹优先，可按名称、大小或类型排序，搜索与分类仅匹配当前目录已加载的条目；还有分页时会明确提示，通过“加载下一页”继续读取。扫描及控制端缓存最多 4096 项；外部增删可能影响分页，刷新可重新读取。普通符号链接可在当前范围内只读跟随，显示链接目标及访问状态；特殊文件不可访问。

切页或旋转保留目录和正在进行的传输；断开或更换目标会清空缓存、取消旧任务。离线仍可浏览功能入口，实际文件操作禁用。

新建目录使用底部的文件夹加号，关闭窗口或旋转保留非敏感名称草稿。刷新失败保留当前列表，页面提供重新加载入口。

底部提供上传、网址下载、新建目录、刷新、视图切换、任务与存储分析图标；宽度不足时，最右侧三点按钮在右下角展开带图标的垂直菜单。点击具体操作后打开独立窗口，只显示该操作相关的表单或任务。下载、删除窗口不再显示上传表单，也不在弹窗内堆叠其他分类入口。关闭窗口不会取消已开始的任务，页面显示任务状态并可重新打开；上传名称草稿保留。文件条目右侧的更多菜单提供属性、主控设备预览 / 播放、被控设备播放、下载、APK 信息与删除，按类型显示。

## 视图与快捷操作

页面只保留导航栏中的“文件管理”标题，页内从根范围与路径开始；操作图标统一放在底部单行工具栏。中间目录独立滚动；路径保持单行，可水平滑动并点击祖先路径返回。所有底部图标提供无障碍名称，更多菜单项同时显示图标与文字。

点击条目数量旁的分类菜单，可筛选文件夹、图片、视频、音频、文档、安装包或其他文件；分类根据文件名后缀识别，不读取文件内容。默认隐藏以点开头的文件，可在同一菜单中选择“显示隐藏文件”。搜索、分类、排序和切换视图仅调整已加载列表，有下一页时需继续加载；不执行全盘扫描。

长按文件或从更多菜单点击“选择文件”，底部切换为该条目的预览 / 播放、属性、下载和删除快捷操作。当前为单项选择，可点另一项切换或点击“取消选择”退出。选择本身不会删除或下载；删除仍按原流程核对目标并确认。视图与显示选项在旋转后保留，目录切换清除选择；失效或受限的链接可查看属性、在原父目录删除链接本身；特殊文件不提供选择动作。

## 上传与覆盖

点击底部“上传文件”，点击“选择本地文件”，手机使用系统文件选择器，桌面使用原生选择对话框。确认当前目标目录并填写目标文件名，再点击“推送选中文件”。上传沿用摘要准备开始时的目标连接；此后断开或重连会使旧上传失效，重新连接同一地址也需重新发起。摘要扫描在每个 64 KiB 分块读取前检查连接；连接变化后不再继续扫描后续分块。若文件提供方正在阻塞当前读取，需等待该读取返回或手动取消。源文件先以流式读取计算 SHA-256，服务再接收数据到同目录临时文件。长度与摘要正确且写入完成后，才原子提交。

默认禁止覆盖同名文件。勾选“允许覆盖同名文件”后，客户端先完成源文件摘要扫描，再显示对话框核对目标路径与当前大小，并再次确认。扫描期间可取消；覆盖授权不会在扫描期间提前开始计时。服务核对目标在确认后是否改变，变化时要求重新确认。覆盖会替换原文件，不能恢复。

部分 Android 共享存储不支持原子“不覆盖”提交。此时默认推送会明确失败，请改用服务收件箱；不要为了上传新文件随意允许覆盖。已确认的覆盖使用原子替换，仍受目标目录权限限制。

## 从网址下载到被控设备

点击底部“网址下载”，粘贴或输入 HTTP / HTTPS 地址后，被控端自动探测文件信息，不会自动开始下载。优先用服务器响应中的文件名填入名称输入框，无法取得时从最终网址推断；名称可手动修改，自动结果不会覆盖手动名称。界面同时显示响应头中的文件大小，服务器不提供大小时明确显示未知；探测失败仍可尝试下载。检查名称与保存位置后点击“开始下载”。文件由当前被控设备联网获取，不经过遥控器缓存。未选择路径时保存到存储卡 `/storage/emulated/0/Download`；“选择保存目录”复用文件管理的 Downloads、服务收件箱和确认后的全盘浏览，进入目录后点击“选择此目录”。可恢复默认下载目录。

文件名称自动填入后仍可修改或清空；留空时使用原网址最后一段，无名称时为 `download.bin`。探测大小仅供下载前参考，实际进度以下载响应为准。同名文件不会被覆盖，更换名称即可重试。页面显示连接、下载、保存、完成、失败或取消状态；已知总大小时显示百分比，未知时显示已下载字节。失败显示原因并可重试；取消或失败清理未完成临时文件，已完成文件保留。关闭任务窗口或返回菜单后下载继续，重新进入文件操作与任务可查看；切换设备会清除当前下载视图并尝试取消旧任务；断线时被控设备上已开始的任务可能继续，服务重启后不恢复任务。不支持断点续传。存储卡不支持原子重命名时，下载完成后会额外流式复制保存，需临时容纳两份文件；保存过程中目标文件可能尚不完整，请等待“下载完成”再使用。服务异常退出可能留下未完成目标文件。

## 大文件下载

在普通文件的更多菜单中点击“下载文件”，服务流式计算摘要，控制端流式下载到本地缓存并校验长度与 SHA-256。完成后点击“保存已下载文件”选择本地位置。手机使用系统创建文件界面；桌面保留已有同名文件，需选择新名称。关闭保存对话框不会丢弃已验证缓存，可重新保存。

上传、下载均使用固定 64 KiB 缓冲，不将整份文件放入内存。单文件协议上限为 1 TiB，实际受两端剩余空间、权限和网络限制；服务上传保留至少 16 MiB 空间余量。界面显示阶段、字节数、错误和取消入口。取消未提交的上传会清理其临时文件，已提交文件保留。没有断点续传或跨服务重启的任务恢复。计算上传摘要时也支持取消，包含文件提供方迟到返回输入流的情况。取消上传或关闭传输客户端时，也会关闭已打开的本地输入流，使支持通过关闭解除阻塞的文件来源退出读取。若文件提供方的打开操作尚未返回，返回后的流会立即关闭；无法保证第三方提供方自身不可中断的打开或关闭操作立即结束。

## 删除

在条目的更多菜单中点击“删除”，核对确认对话框里的准确路径。确认只适用于原连接；切换设备或重连后旧提案不能提交，需重新准备操作。目录删除包含全部子项，操作不可恢复。删除符号链接只移除链接本身，不删除指向的文件或目录；不允许通过链接父目录删除子项。递归删除不跟随链接，也不跨文件系统挂载点。删除按任务执行，显示已删除项数，可取消后续处理；取消或中途错误不会恢复已删除项。

删除从文件条目的更多菜单发起，并逐项核对确认；取消不会执行删除。模型准备的提案不再提供分散的查询入口，也不会自动执行。全盘范围包括服务可修改的系统和应用目录，务必核对路径。

图片、音乐与视频可通过“在被控设备播放”查询并启动目标播放器，详见[媒体投送](media.md)。

## APK 信息

上传 APK 后，可点击该文件的“APK 信息”，核对包名、版本、完整文件 SHA-256 和声明证书指纹。这个入口只解析，不安装或更新应用，也不验证签名真伪。整文件摘要走长任务，显示已读取字节，并支持取消；取消保留原 APK。v2/v3/v3.1 可读取声明证书指纹，v1 当前只识别记录存在并显示解析未支持。版本名称若为资源引用可能显示“未读取名称”；单 APK 安装与更新使用下面的确认流程，独立的安装前密码学签名验证仍未实现。

## 安装与更新 APK {#apk-install}

读取“APK 信息”后点击“准备安装此 APK”。已有应用的替换需要先勾选“允许覆盖安装现有应用”。准备阶段创建私有匿名副本、显示拷贝和摘要核对的处理进度，可取消，原文件保留。

核对弹窗中的包名、当前/待安装版本、用户、SHA-256 和声明证书。覆盖安装可能改变该包所有用户使用的程序代码，应用升级迁移也可能改变数据。确认仅适用于准备提案时的连接；切换设备或重连后需重新准备。确认后交给 Android 包管理器验证并安装，提交阶段不可取消。控制端核对完成结果的包名、版本、Android 用户及 APK SHA-256 与确认提案一致，错配响应不会显示安装成功。安装从文件的 APK 信息面板准备并核对确认，不再提供模型待确认安装查询入口。

支持单个 APK 或 base 与 split APK 的整组安装；系统及特权包替换、匿名暂存不受支持的文件系统会拒绝。不会将签名冲突变成卸载重装，也不自动允许降级或授予权限。提案不跨服务重启恢复；断线或超时后通过应用信息确认最终状态。

### base 与 split 多包安装 {#split-apk}

先将 base 和所需 split APK 上传到同一目标文件范围（收件箱、Downloads 或已确认的全盘范围）。逐个点击“APK 信息”，再点“加入多包安装”。选择清单保留已解析的文件，允许移除或继续加入；无需同时将所有文件内容读入内存。查看清单后勾选是否覆盖已有应用，再点击“准备安装整组 APK”。

整组最多 32 个 APK、总大小最多 4 GiB，必须包含一个 base，包名与版本一致，split 名称唯一。客户端与目标服务都检查这些条件；已能读取的声明证书指纹也必须一致。缺少依赖和实际签名有效性由 Android 包管理器验证，不把元数据检查当作完整签名验证。

每个文件都通过 64 KiB 缓冲复制到目标私有匿名暂存，并重新核对完整摘要。独立确认弹窗列出整组路径、大小与摘要；确认后通过一个 Android 安装会话写入并统一提交，失败时尝试放弃会话，不通过逐包安装留下部分结果。取消准备或拒绝确认保留源文件；重连或切换目标清除已选清单。当前选择的是独立 APK 文件，不自动解压 `.apks`、`.xapk` 或 `.apkm` 容器。

## 只读存储分析 {#storage-analysis}

从底部图标或更多菜单进入“存储分析”，点击“分析此目录”，统计当前所选目录及其子目录，查看后缀分类和最多二十个逻辑大小最大的文件。扫描显示已访问项数并可取消，不删除文件或应用数据。取消请求处理期间保持忙碌，结束后才可重新分析，避免重复启动扫描；取消清理等待最多五秒。全盘范围仍须通过已有确认入口选择；只统计服务可访问的内容，不自动提权。

逻辑大小与文件系统分配块分别显示，硬链接去重；二者都不等于能释放的空间。稀疏文件、块共享和文件系统策略会产生差异。日志/临时后缀只是文件名分类，不保证文件无用；分析不识别应用缓存，也不使用 pm clear 清除应用数据。需要删除时在文件列表核对并沿用逐项确认。

最多扫描 100000 项、64 层和 120 秒，不跟随符号链接或跨不同文件系统。达到上限、无权限或检测到目录变化时会标注报告不完整，并显示前八项错误。报告不是事务快照，其他程序仍可能修改内容。断线或服务重启不会恢复旧扫描；可重新分析。

保存对话框尚未领取的下载缓存，在断开或切换目标清理时删除并失效，迟到保存回调不能再领取。已经交给本地保存流程的文件由该流程持有，可完成此前授权的保存；若保存失败，旧连接代次的文件不会恢复到新目标缓存。

## 创建目录工具

服务与模型工具现在支持 files.mkdir/files_mkdir，在选定根目录创建一个不存在的新目录。需填写相对路径，父目录必须已存在，不覆盖已有文件或目录。支持该工具的服务会在 App 文件页显示“新目录名称”和“创建目录”。在当前目录输入单个名称；离线、加载中、传输中或名称无效时禁用提交，成功后刷新目录。同样可通过公开工具协议或文字模型任务调用。

客户端在显示直接删除确认前核对提案操作、根目录、相对路径、人工确认要求和递归标志；与原请求不一致时拒绝进入确认，不提交删除。

删除进行中若进度查询失败，客户端会向原连接尽力取消尚未结束的任务，并保留原错误。断线时无法保证取消送达；已经删除的内容不会恢复，应重新连接并刷新目录核对。

递归删除在目录枚举和进入每个子项时都校验文件系统设备号，拒绝跨挂载点。直接选择挂载目录作为删除范围时，边界以该目录所在文件系统为准。

进度响应必须属于最初的传输或删除任务；任务 ID 不一致时停止操作，并只对原任务尝试清理。删除进度还须保持删除类型与原根目录一致，不接收另一任务的完成状态。

目录列表、属性查询或新建目录请求被取消后会退出加载状态，可重试；取消不等于目标操作一定未执行，新建目录需先刷新确认现状。

目录响应含无效文件名、未知类型、负数大小或同页重复名称时，会报告错误并保留原列表，可刷新重试。符号链接按目标类型显示，并明确标注链接、目标及失效/越界/循环/无权限等原因；特殊文件不可访问。

属性查询若返回的类型与所选文件/目录不同，或返回负数大小，会报告响应不匹配。目标条目可能已变化，刷新列表后再查询。

分页继续游标必须对应本页最后一个文件名；空页带游标或游标与条目不一致时会报错，避免静默遗漏文件。

目录分页按目标 UTF-8 字节序校验。后续页含游标之前或重复的名称、条目顺序倒退时保留缓存并提示刷新；目录不是原子快照，浏览过程中新增的文件仍需刷新才能完整观察。

开始新的属性查询时会清除上一次属性，查询失败或取消后不再展示旧条目的属性；列表缓存仍保留，可重新选择查询。

## 缩略图、预览与播放 {#file-preview}

图片、音视频和文本在列表与网格中按需加载缩略图：Android 显示图片、视频首帧、音频内嵌封面与文本摘要；无封面、格式不支持或读取失败时保留类型图标。桌面显示图片与文本缩略图，音视频保留类型图标。缩略图仅缓存在内存，刷新、切换目录或连接后重新读取；不会自动下载整部影片。

点击图片或文本可在主控设备预览，属性仍在更多菜单中。图片支持双指缩放、拖动与重置；单张源文件上限 16 MiB，解码后限制像素数。文本支持 UTF-8、带 BOM 的 UTF-16 与 GB18030，显示编码，最多读取前 256 KiB，超出时提示下载完整文件；内容可选择复制，HTML 和脚本只按文本显示，不执行。

音视频明确区分播放位置：

- **在主控设备预览 / 播放**：Android 在预览窗口使用内置播放器，可播放、暂停、拖动进度与停止；初次打开先准备，点击播放后开始，进入后台暂停。桌面通过“在主控设备打开播放”交给系统处理媒体流，播放期间保持预览窗口打开。
- **在被控设备播放**：从更多菜单或预览内的“改为在被控设备播放”进入目标播放器选择，确认后在被控设备打开。目标画面与媒体状态用于确认实际播放，不能把启动成功当作已经播放。

媒体按范围读取，打开预览不会启动被控设备播放器，不复制到目标 Downloads。关闭、离开预览或切换连接会取消读取并尽力释放只读资源；未成功释放的预览资源闲置五分钟失效。原文件变化时拒绝继续读取，需要刷新重开。编码或系统解码器不支持时显示错误，可下载后用其他播放器打开。

APK 条目按需读取安装包自身的真实图标，尚未安装也可显示；图标失败时保留安装包图标。点击 APK 或选择“APK 信息”可读取包名、版本、拆分包、大小、摘要与声明证书，然后选择“在被控设备安装此 APK”。安装只发生在当前连接的被控设备，仍须独立确认；预览与读取图标不会安装。覆盖与 base/split 安装规则见上文。

Android 系统分享菜单可选择“AI 遥控”：网址可进入预填的下载表单并复用目录选择；文字可作为电视输入编辑；单个文件可上传到电视 Download，完成后选择电视播放器。先选择或连接目标，再明确提交。暂不支持一次分享多个文件；若文件授权失效，需重新分享。关闭面板保留待处理内容，顶栏文件按钮可重新打开，移除后清空。
