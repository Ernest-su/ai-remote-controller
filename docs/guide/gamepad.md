# 游戏手柄输入原型

Android 从遥控器右上角“切换遥控器类型”选择“游戏手柄”；JVM 桌面仍从功能网格打开。手机与 JVM 桌面共用页面，可发送方向、A/B/X/Y、L1/R1/L2/R2、Start/Select 与摇杆按键。展开“更多按键与组合设置”，选择 100、300 或 1000 毫秒后，点击按钮发送一次有限时长按下/抬起事务。组合区域最多选四个按钮；X/Y 滑条为 -1..1，正 X 向右、正 Y 向下。滑条和选择只编辑草稿，点击“发送组合与摇杆”才注入；结束后选中按钮释放、轴值回零。

“重置输入草稿”只修改本地表单；“释放按钮并回中”先等待在途事务结束，再提交全部受控合成按键的抬起和轴值零。离线禁用实际发送，草稿仍可编辑并在旋转/导航后保留。输入进行中禁止重复发送；切页或控制端断线不撤销已被服务接受的事务，服务继续完成释放。重新连接后需要手动操作，不恢复按住状态。

这是合成 GAMEPAD/JOYSTICK 来源输入，不注册有轴范围的硬件设备。部分游戏只接受已注册控制器，因此可能忽略输入；接口提交成功不证明游戏支持。短时 framework 适配的启动耗时也不适合低延迟连招。系统权限拒绝、服务或系统被强制杀死、应用焦点变化时无法保证完整序列，应核对目标状态并按需释放。当前只支持 X/Y 与有限按钮组合，持续摇杆、右摇杆、物理控制器注册及第三方游戏兼容仍待后续实现。

## 持续虚拟手柄工具原型

新版二进制服务增加 `gamepad.virtual_capabilities`、`gamepad.virtual_open`、
`gamepad.virtual_update` 和 `gamepad.virtual_close`。手机/JVM 手柄页的独立“持续虚拟手柄”分组复用这些工具。手动开始后可按住/松开按钮，
拖动左右摇杆，松开/取消回中；“全部释放并回中”清空当前输入。无障碍点击发送100ms按压。
持续会话期间禁用有限输入提交。离页、旋转、Android后台、桌面失焦或断线停止，
不保存按住状态、不自动恢复，需手动重启。

此原型需要 root 和 Linux uinput v5，固定使用 `/dev/uinput`，注册带 UUID 的独立设备。
不会修改实体手柄或输入映射文件。一个服务最多一个活动会话，只有建立它的 WebSocket
连接可更新/关闭。更新是完整状态快照，缺省按钮和轴回到零；序号严格递增。
按钮包含 A/B/X/Y、肩键、Start/Select 和摇杆按键；左摇杆 X/Y，右摇杆 Z/RZ，方向帽 HAT_X/Y。

客户端需持续发送快照或心跳。两秒无更新时服务尝试释放按钮并回中；三十秒无更新关闭，
会话最多一小时。连接断开、明确关闭和服务停止销毁设备。写入失败也关闭会话。
目标设备已验证内核/Android 注册、序号/归属拒绝和关闭/断线清理。
只读取自建 UUID 设备的事件，验证按钮边沿、左右摇杆及方向帽、相同快照心跳不重复按下、
失联后释放/六轴归零及再次按下后的明确释放。实测首次按下后 0.8 秒补一次心跳，
约 2.901 秒时自动释放；这是单次内核时序观测，不能当作网络延迟或游戏性能保证。
自建 Android 接收器还观察到正数设备 ID、对应设备名、按钮边沿及左右棒/方向帽数值与回中，
证明输入到达该 Activity。它不代表第三方游戏兼容；真实游戏、物理控制手机交互、
网络低延迟与其他固件尚未验收。

共享 JVM 控制器也已通过真实目标专项：完整快照到达接收器，心跳持续保持按住，
显式释放使六轴回中，停止时收到按钮抬起且设备被移除。该测试调用生产控制器，
JVM Compose专项进一步通过实际页面触摸到接收器的按钮/左右摇杆及回中，
按住按钮时移除页面也收到抬起并销毁设备；物理手机生命周期和第三方游戏仍单独验收。

焦点状态专项已核对失焦释放与恢复焦点不自动重启，使用注入窗口状态和真实目标接收器；
操作系统原生窗口焦点事件及物理手机后台/旋转仍待单独验证。

手机进入手柄页会自动切换横屏，可向左或向右横向持握；离开手柄页恢复原方向策略。方向变化或 Activity 重建会释放持续输入，恢复后需手动开始；输入草稿沿用原有重建恢复规则。

从手柄页进入设备页时会恢复原方向策略，返回手柄页再次横屏，输入草稿保留；顶部返回与系统返回都遵循同一恢复规则。

实机验收已覆盖 A/B 两键与六轴同时保持时退到后台的释放、归零和虚拟设备回收；组合状态通过控制器提交。多指触屏并发和具体游戏仍需分别验证。

横屏宽布局左侧圆形左摇杆、右侧 Y/X/B/A 菱形圆键，SELECT/START 居中；右摇杆、肩键、方向帽和原有限时组合控制均保留，较短窗口可滚动。真实手机已验收左右摇杆与 A 键三指同时保持，以及后台释放和设备回收。此结果仅覆盖该组合，具体游戏仍需验证。

有限按键/摇杆请求绑定开始时的目标连接；执行后连接变更或释放未确认会报告错误，请核对目标状态。
