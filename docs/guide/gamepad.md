# 游戏手柄

Android 从遥控器右上角“切换遥控器类型”选择“游戏手柄”；JVM 桌面从功能网格打开。标题旁的手柄类型菜单可选择以下布局，root 与非 root 共用：

- **NES 经典手柄**：十字方向键、A/B、SELECT/START，适合 NES 等使用数字方向的游戏。
- **双摇杆手柄（默认）**：左右摇杆、X/Y/A/B、SELECT/START，适合使用模拟轴的游戏。

选择后布局与输入映射立即切换，离线也能浏览选择。运行中会先释放旧按键并回中，等待确认后启用新控件，无需重新点击开始；切换前按住的输入不会带到新布局。类型在导航、旋转和停止/开始后保留，应用进程重启后恢复默认。

连接后点击“游戏手柄”标题旁的播放图标开始，启动后同一图标切换为停止；处理中暂不可重复点击。按住按钮操作，松开或取消手势释放；拖动左右摇杆，松开或取消回中。十字键支持斜向和方向与跳跃同时按住，相反方向抵消，松开其中一个恢复另一个。支持多指同时操作；键盘按下/抬起等价，无障碍点击发送 100ms 按压。点击标题旁的停止图标结束本次输入并释放、回中。离线仍可浏览页面，实际操作禁用。

NES 使用大十字键和圆形 A/B：方向键优先72dp，A/B优先88dp；双摇杆主键优先80dp，SELECT/START高度至少64dp。布局随视口调整，窄屏 A/B 改为竖排，为拇指操作保留空间。

操作区只保留摇杆和游戏按键，不显示底部说明、启停或复位按钮。页面固定在当前视口，不能水平或垂直滚动；宽屏控件同排，窄屏分为固定两行，短屏收紧布局留白。启停、状态变化与多指拖动不会推动操作区。

## 输入方式

开始时自动检测被控端能力，不需要切换页面：

- root 且 uinput 可用：通过 `/dev/uinput`（v5 或更高版本）注册独立虚拟手柄，持续更新按钮与左右摇杆，NES 十字键使用 HAT_X/HAT_Y；不修改实体手柄或输入映射文件。
- uinput 不可用（包括非 root）：通过 Android 系统输入接口发送合成 GAMEPAD/JOYSTICK 事件，按住期间串行重复 100ms 有限事务。左摇杆使用 X/Y，右摇杆使用 Z/RZ，NES 十字键映射为 DPAD 方向按键；每次事务自动释放并回中。这种方式存在输入间隙和启动耗时，不保证低延迟或连续长按效果。

非 root 需要被控服务具有 ADB shell 等系统输入注入权限，普通应用权限不足。合成输入不注册硬件手柄，部分游戏可能忽略。虚拟设备注册成功、系统接受输入或请求成功，都不证明具体游戏实际消费输入。

## 生命周期

手机进入手柄页自动切换横屏，可向左或向右横向持握；离开恢复原方向策略。离页、旋转重建、Android 后台、桌面窗口失焦或断线停止输入，恢复后需要手动开始；按住状态不会保存或自动恢复。打开设备页再返回遵循同一规则。

更新回复超过1秒时，先清空当前按住状态，立即用更高序号发送回中快照，最多等待500ms；单次丢失回复不重建手柄。探测仍无回复、会话失效或请求暂时失败时，再在原设备连接内自动重建手柄会话。恢复清理最多等待500ms，随后按150/300/600ms间隔最多重试三次；连续正常运行5秒后重置重试次数。重连中标题图标显示进度，仍可点击停止，游戏按键暂时禁用；恢复后需要重新按下，不重放旧输入。参数或响应校验失败不自动重试。底层设备连接断开后仍按上述生命周期规则停止，设备重新连接不会自动开始手柄。

虚拟手柄每个服务最多一个活动会话，由建立它的连接独占。同一连接重新打开会先释放并替换自己的旧会话，其他连接不能替换。每个会话使用唯一的设备路径，避免 Android 合并快速重建的新旧手柄。两秒无更新时尝试释放并回中，三十秒无更新关闭，会话最多一小时；断线、明确关闭或服务正常停止时销毁设备。合成输入在停止时等待已接受的有限事务结束，再尝试重置；强制终止或系统权限拒绝时无法保证释放。

如果 NES 游戏能跳跃但无法左右移动，选择 NES 经典手柄，并在模拟器的手柄设置中核对方向与 A/B 绑定。不同模拟器可能需要手动绑定，选择类型不代表已经验证游戏消费输入。

完整工具接口见[手柄工具](../reference/tools.md#gamepad)；内核、厂商权限与第三方游戏兼容性需在目标设备上核对。
