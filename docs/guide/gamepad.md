# 游戏手柄

Android 从遥控器右上角“切换遥控器类型”选择“游戏手柄”；JVM 桌面从功能网格打开。root 与非 root 使用同一个界面，只显示左右摇杆、X/Y/A/B、SELECT 和 START。按钮组合、时长选择、方向键、肩键和摇杆按键已从界面移除。

连接后点击“开始手柄”，按住按钮操作，松开或取消手势释放；拖动左右摇杆，松开或取消回中。支持多指同时操作；键盘按下/抬起等价，无障碍点击发送 100ms 按压。“全部释放并回中”清空当前输入，“停止手柄”结束本次输入。离线仍可浏览页面，实际操作禁用。

## 输入方式

开始时自动检测被控端能力，不需要切换页面：

- root 且 uinput 可用：通过 `/dev/uinput`（v5 或更高版本）注册独立虚拟手柄，持续更新按钮与左右摇杆；不修改实体手柄或输入映射文件。
- uinput 不可用（包括非 root）：通过 Android 系统输入接口发送合成 GAMEPAD/JOYSTICK 事件，按住期间串行重复 100ms 有限事务。左摇杆使用 X/Y，右摇杆使用 Z/RZ；每次事务自动释放并回中。这种方式存在输入间隙和启动耗时，不保证低延迟或连续长按效果。

非 root 需要被控服务具有 ADB shell 等系统输入注入权限，普通应用权限不足。合成输入不注册硬件手柄，部分游戏可能忽略。虚拟设备注册成功、系统接受输入或请求成功，都不证明具体游戏实际消费输入。

## 生命周期

手机进入手柄页自动切换横屏，可向左或向右横向持握；离开恢复原方向策略。离页、旋转重建、Android 后台、桌面窗口失焦或断线停止输入，恢复后需要手动开始；按住状态不会保存或自动恢复。打开设备页再返回遵循同一规则。

虚拟手柄每个服务最多一个活动会话，由建立它的连接独占。两秒无更新时尝试释放并回中，三十秒无更新关闭，会话最多一小时；断线、明确关闭或服务正常停止时销毁设备。合成输入在停止时等待已接受的有限事务结束，再尝试重置；强制终止或系统权限拒绝时无法保证释放。

完整工具接口见[手柄工具](../reference/tools.md#gamepad)；内核、厂商权限与第三方游戏兼容性需在目标设备上核对。
