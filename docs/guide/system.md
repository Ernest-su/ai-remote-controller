# 系统管理

从功能菜单打开“设备信息”，在“系统管理”中准备锁屏、重启或关机。新版服务需要以 root 运行，并通过 Android 框架权限与接口检查；非 root 或离线连接禁用准备入口；框架权限或接口不可用时准备操作返回错误，不会自动提权。

准备不会执行。核对弹窗中的目标名称、操作与影响，然后确认或取消；提案创建后两分钟过期，待确认列表返回剩余有效期，客户端等待到期会拒绝并关闭弹窗；断开连接后失效。系统管理仅保留用户手动准备操作与确认，不再提供模型待确认系统操作的查询入口；模型不能替代用户确认。手机与桌面共用流程；提案不写入持久存储。

重启或关机会中断任务与连接，关机后可能需要现场开机。提交后无法取消。返回“请求已提交”只表示框架调用返回；连接断开、超时或没有响应都不能证明动作成功，请观察设备实际状态，避免立即重复提交。提交后断开或切换目标时，App 保留“先前目标可能已提交”的核对提示，旧提案仍被移除；这条内存提示不代表新目标执行了操作，重新准备操作时会重置。

目前完成工具、框架桥接与 App 确认流程的实现和 fixture 回归，尚未执行物理设备的锁屏、重启或关机验收。

系统状态工具 `device.system_state` 可只读查询交互、锁屏与是否配置安全凭据（用户 0）。未知字段显示为 null；不会读取密码或修改凭据，查询结果须结合设备实际表现，不自动将已有操作标成完成。在手机与桌面“设备信息”页点击“刷新电源与锁屏状态”查看。不可用字段显示未知，断线或切换目标清空旧观察值；查询不自动把之前的动作标为完成。

确认提交系统动作前，App 清除旧电源/锁屏观察并取消旧查询，避免把提交前快照当成新状态；取消确认不清除观察。提交后需手动刷新并核对实际设备，刷新结果不自动关闭“仍需核对”的提示。

状态面板显示最近一次快照的控制端收到时间（含时区偏移），不是持续更新的实时状态，也不是目标设备的墙上时钟。要获取新观察请点击刷新；连接变化或系统操作提交前清理快照时，时间标签一并清除。

模型不能用普通电源按键代替系统确认；锁屏、重启和关机使用独立提案。首页用户手动电源按钮保持可用。
