# 故障排查

## 连接失败

核对目标 IP、ADB 端口及目标 ADB 状态。TCP 首次授权在目标屏幕完成；配对码端口不能当成无线连接端口。无线配对后发现失败时，检查同子网、无线调试状态，或填写目标首页的实际连接端口。

应用报告取消后应退出忙碌状态；连接失败不会删除此前成功保存的设备。目标重启可能改变地址或端口。

## 局域网发现列表为空

确认 runtime 正在运行，控制手机和目标 IPv4 地址可互通。检查 Wi-Fi 客户端隔离、组播过滤、VPN 与 VLAN。ADB 发现成功不代表 `_airc._tcp.` 服务已发布；二进制发现也不代表 ADB 管理通道可用。

## 文字请求失败

确认配置已保存到当前目标；目标自身能够访问 API 地址；模型支持工具调用。查看目标返回的 HTTP/工具错误。发送图标禁用时检查连接、模型配置、输入是否为空或上一个请求是否仍在执行。

## 版本安装失败

核对 HTTPS 地址、相邻 `.sig`、发布公钥、协议及应用版本范围。签名不匹配时应由发布者修正，不能绕过验证。确认目标 ABI 受支持、临时目录可写且空间足够。

## 收集诊断

记录应用/runtime 版本、系统版本、ABI、连接方式、网络、复现步骤和错误文本。目标运行日志位于 `/data/local/tmp/airc/state/runtime.log`。分享前删除密钥、配对参数和私人内容；日志文件名及状态目录可参考[CLI](reference/cli.md)。
