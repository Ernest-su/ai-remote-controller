    快速开始¶

    准备¶

    准备一台控制手机和一台可通过 ADB 访问的目标 Android 设备，两者连接可互通的局域网。控制手机无需开启本机无线调试；产品不使用 USB 连接。无线配对取决于目标系统支持，未提供该功能的目标可使用已经启用的 TCP ADB。

    控制端最低支持 Android 8.0 / API 26；目标 runtime 提供 ARM64、ARMv7、x86_64 三种 ABI。普通按键无需模型，AI 文字任务需要目标可访问的兼容模型接口。

    获取与安装¶

    维护者公开的生产签名 APK 位于 GitHub Releases。若尚无公开版本，可从源码构建：

    export ANDROID_HOME=/path/to/android-sdk
export ANDROID_NDK_HOME="$ANDROID_HOME/ndk/28.2.13676358"
./gradlew :androidApp:assembleDebug --no-daemon

    开发机需要 JDK 17、Android SDK 36、NDK 28.2.13676358、Rust/Cargo/rustup 和 Python 3.11+；Gradle daemon 按仓库配置使用 JetBrains JDK 25，首次自动获取。构建会将三 ABI runtime 打包到 APK，无需单独安装目标程序。详细环境见从源码构建。

    debug APK 输出为 androidApp/build/outputs/apk/debug/androidApp-debug.apk，安装到控制手机。debug 与生产 APK 使用不同证书，不能互相直接覆盖安装；如需切换，应在卸载前确认能够重新配置模型与设备信息。

    生产签名、六项 GitHub Secrets 和草稿 Release 的使用方法见签名与发布。只有公开的 Release 才能进入 App 在线更新入口。

    首次连接¶

    1. 在目标设备开启适用的 ADB 连接方式，并准备完成目标上的授权。
    2. 打开绿色电视与 AI 遥控器图标的「AI 遥控」，首页始终为遥控器。
    3. 点击右上角连接状态进入设备页。附近、历史与局域网服务合并显示；可选择已有设备连接，或展开「连接目标设备」填写 TCP、配对码或二维码信息。
    4. 已发现设备的服务连接失败时，应用自动尝试 ADB 部署（未保存端口时使用 5555）并提示；失败后展开手动连接并填入目标 IP，可修改端口或切换配对方式。保持目标在线，等待校验、推送与启动完成。配对端口和连接端口不同，具体步骤见连接设备。
    5. 设备页顶部显示连接进度与结果，无额外完成弹条；显示「已连接」后，试用方向、确认、返回、主页或音量。按键和应用启动无需模型。

    连接时会传递 App 语言，设备能力和权限错误按中文或英文显示；更改语言后重新连接生效。

    快速连按提示操作队列已满时，等待已有操作完成后再重试；服务会保留连接和已接受的操作，不自动重试被拒绝的按键。

    普通按键使用独立遥控通道和预热输入桥接，不受媒体查询或文件操作排队影响。若提示按键结果不确定，请先核对目标状态；服务仅尝试释放按键，不会自动重复按下。

    连接时自动核对被控服务的版本与二进制摘要，不匹配时通过 ADB 更新配套程序并重新连接，保留现有配置；ADB 未授权或更新失败时不会继续使用旧服务。版本与摘要均匹配时直接复用连接。

    目标程序默认安装到 /data/local/tmp/airc/airc-runtime，服务端口默认 9876，默认以 ADB shell 身份运行。在「功能 → 运行权限」可选择优先 root；只在目标已支持并授权时使用，不为目标获取 root。

    若部署提示端口被占用，请先核实并停止占用进程，再重试；残留 root 服务需要 root 权限停止。不要删除程序或状态目录来代替停止服务。处理方法见设备端服务与更新。

    协议不提供用户登录鉴权，请在可信局域网使用。删除、卸载、缓存清理、安装和系统管理使用各自确认流程；普通遥控和文字任务不会逐步确认。

    第一个 AI 任务¶

    1. 左上角菜单进入三列功能网格，打开「模型配置」。
    2. 填写 API 根地址、API Key 与模型名称，点击「保存到 App」。模型列表可手填，也可手动拉取并缓存。
    3. 连接目标后点击「更新到目标设备」。本地保存不会自动同步，目标必须能访问对应提供商。
    4. 目标未配置模型时，标准遥控器底部只显示不可点击的配置提示，隐藏输入框与发送按钮。更新到目标设备成功后，回到遥控器底部输入任务，点击发送图标或键盘发送键；较长任务可在「文字指令」页编辑。
    5. 查看执行反馈并核对目标实际行为，完整输出从「执行结果」进入。

    空白、离线、目标未配置模型或已有文字请求进行中时禁止发送。草稿在导航与旋转后保留，只在请求被接受后清空。反馈每次更新后显示五秒，再回到播放状态；切页或旋转不会重新显示已过期反馈。更多说明见遥控与文字指令和模型配置。

    常用入口¶

    入口 用途
    右上角连接状态 设备连接、显示名、断开与网络诊断
    右上角遥控器类型 标准遥控器、触控板、数字键盘、播放控制与游戏手柄
    功能 → 应用管理 搜索、启动、应用信息及确认后的缓存清理/卸载
    功能 → 设备预览 截图保存、分享与动态预览
    功能 → 文件管理 浏览、上传、下载、目录、APK 与存储分析
    文件管理 → 媒体 目标播放器、HTTP 媒体流与本地播放副本
    功能 → 设备信息 只读系统与硬件信息、电源观察与系统管理
    功能 → 设置 跟随系统、亮色或暗色，以及遥控按键震动开关（点按短震、长按弱震、松开或取消即停，同键重复按下会清理旧计时，快速连按不延续长按反馈），离线可修改并本地保存
    功能 → 服务管理 查询、更新、重启和停止服务，需要已保存的 ADB 连接

    功能子页返回功能菜单，菜单返回遥控器；设备页返回来源页。短窗口、大字体或键盘展开时，遥控按键区域可以滚动，底部文字输入入口保留。

    桌面联调可从项目目录运行 ./gradlew :desktopApp:run --no-daemon，使用宿主机 adb；操作与限制见桌面指南。遇到问题先阅读故障排查。

    Android 进入“设备预览”后自动开启动态预览，可直接触摸操作目标，通过动态预览标题右端的全屏图标放大画面，左侧遥控器图标可在普通或全屏模式展开悬浮遥控；两种模式均保持原比例，切换后持续或自动恢复预览；返回前台和旋转后自动恢复，不再提供开始、停止按钮。详见设备预览与动态预览。

    “文件管理”提供列表/网格、图片与媒体缩略图、文本摘要、目录内搜索与分类、长按选择和底部快捷操作；点击文件可预览，音视频明确选择在主控设备或被控设备播放，APK 支持真实图标、信息预览及在被控设备安装；上传及删除沿用独立确认与任务进度。详见目标文件管理。

    游戏手柄在 root 与非 root 下使用相同的左右摇杆、X/Y/A/B、SELECT/START 布局，连接后点击“游戏手柄”标题旁的播放图标开始，同一图标可停止；操作区固定，不支持横向或纵向滚动。手柄请求超时会清空输入并在原连接内快速自动重连，最多连续重试三次；点击标题图标可中止重连。root/uinput 可用时创建虚拟设备，非 root 使用重复短时合成输入，连续性与游戏兼容性有限。详见游戏手柄。

    Android App 打开后自动尝试连接最后一次成功连接的设备；意外断连后按 3、6、12、24 秒递增重试，之后每 30 秒重试。手动取消连接、断开或停止服务后暂停自动重连；主动连接其他设备会切换目标。自动连接仍核对配套版本，必要时通过已保存的 ADB 方式部署，不重放遥控按键或文字任务。

    应用管理的图标在滚动返回时复用当前连接缓存；刷新或重连后重新加载。

    应用、文件与设备信息页不再展示模型待确认提案的分散查询入口。卸载、缓存清理、删除、安装与系统操作从具体目标的手动操作开始，仍须核对原有确认弹窗。

    应用管理点击应用行进入应用详情，可查看权限并按目标支持情况管理授权、强行停止、停用/启用、清理缓存、清除全部数据及卸载。权限列表优先显示可操作的开关。修改需逐项确认，成功后自动刷新目标状态；系统及特权应用仅供查看，离线禁用实际操作。
