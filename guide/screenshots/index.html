    设备预览¶

    从遥控器左上角打开功能菜单，选择“设备预览”。连接支持 device.screenshot 的服务后，点击“获取 / 刷新截图”。应用先请求捕获，再下载临时 PNG，成功后显示保持原比例的预览。获取过程中禁用重复请求；服务缺少所需工具时需更新为与 App 配套的二进制。

    点击“保存 PNG”保存原始图片。手机使用系统文件选择器，无需全盘存储权限；桌面使用原生保存对话框，同名文件不会覆盖。预览缩放不影响保存的原图。

    手机的“分享截图”打开系统分享面板，由用户选择接收应用。分享使用应用私有缓存与临时读取授权，不公开整个缓存目录。缓存最多保留八个分享副本，较早副本会被后续分享清理；长期保留请使用保存操作。桌面暂未提供系统分享。

    截图保留在当前应用会话内，切页和手机旋转可继续浏览。断开连接或切换目标会清空预览并取消捕获，较早请求不会覆盖新设备画面。已经选择保存的截图副本独立于后续预览，手机旋转后返回文件选择器仍能保存所选副本；进程退出不会恢复这份内存副本。

    截图是单张目标画面，不是实时投屏。受系统保护的内容可能显示黑色，命令失败、图片无效或资源过期都会显示错误，可重新获取。工具与下载的细节参见工具参考。

    Android 动态预览：ascrcpy¶

    Android 动态预览改用 ascrcpy 的 ADB、scrcpy 4.0 与 MediaCodec 链路。先在设备页通过 ADB 连接目标，再进入“设备预览”，页面自动开启动态预览，不再需要开始或停止按钮；失败时保留原因，并可点击“重试预览”。默认清晰档为最长边 1920、8 Mbps、60 fps；可选均衡（1280、4 Mbps、30 fps）或流畅（720、2 Mbps、30 fps），保持目标比例，无音频。档位保存在手机，切换会按所选分辨率上限重启视频流，等待新画面载体就绪后恢复；预览区域大小保持不变，画面始终等比缩放。目标分辨率低于档位上限时不会放大。离页、后台或连接丢失时关闭会话，回到前台、旋转恢复或 Surface 重建后，在连接就绪时自动恢复；方向重建沿用当前档位。预览使用独立 ADB 会话，不替换目标 Rust 二进制服务。目标临时 server 文件使用本次会话唯一名称并在结束后清理。

    JVM 桌面只提供单张截图、刷新和保存，不提供连续画面或动态预览。

    停止、断线或失败后会释放旧 Surface 并创建空白画面，最后一帧不继续显示；连接失败仍保留错误提示，用户可手动重试。进入后台会停止采集，回到页面后自动恢复。

    连接成功后，视频启动与首帧等待最多 45 秒，超时停止本次会话并显示错误，可手动重试。ADB 连接自身也有连接超时；不保证每台设备都能在相同时间内完成初始化。

    截图请求被取消后会退出加载状态，可以重新刷新；已选定的导出快照仍按原保存/分享流程处理。

    目标方向改变时，ascrcpy 视频尺寸元数据触发解码器重新配置，预览按新尺寸继续渲染。控制手机自身旋转或切后台时停止旧会话，页面恢复后自动开始新会话。

    动态预览标题最右侧是全屏图标，左侧是遥控器图标；普通界面不显示预览尺寸和编码参数。点击全屏图标放大画面，全屏右上角使用遥控器与退出全屏两个图标，系统返回也可退出全屏。普通与全屏保持同一个画面承载位置，不因切换主动停止视频；系统必须重建 Surface 时自动恢复。画面始终保持目标比例，空余区域不参与触控，可直接点击、滑动或多指操作目标。

    普通预览与全屏共用可拖动的悬浮遥控，点击遥控器图标展开或收起，关闭图标也可收起。默认使用紧凑按键布局；点击关闭图标左侧的布局图标切换为完整遥控后，遥控按键、文字输入和执行反馈与首页相同，并整体等比缩小：竖屏宽为屏幕宽的三分之一，横屏宽为屏幕短边的一半，最小宽度为144dp以容纳顶栏操作；短屏可在遥控内部滚动。按住左上角四向箭头手柄或其右侧空白直接移动，即可拖动，无需等待长按；浮层其他位置也可长按后移动，包括按键和输入区。普通滑动仍可滚动内部内容，开始拖动会取消当前按键并停止继续发送；松手结束，浮层不会超出当前页面。切换全屏或收起后再展开保留文字草稿，只有请求被接受后才清空。

    悬浮遥控默认使用紧凑布局，方向、确认、返回、主页、菜单、音量与播放按键保持至少 48dp；可点击布局图标恢复缩放的完整首页遥控。顶栏“电视输入”可打开独立中文输入面板。

    全屏时，右上角工具栏和悬浮遥控外框为透明背景；紧凑、完整两种布局的按键和状态只保留局部半透明深色衬底、细描边与清晰前景，空隙透出目标画面。按键和文字使用清晰前景，浮层整体透明度由设置控制。透明空隙不会把触控传到目标，操作画面请点击遥控器外的视频区域。退出全屏后恢复普通预览的亮暗主题。

    浮层右上角依次为布局切换与关闭两个图标，布局图标随当前紧凑/完整状态变化；外框始终保留细半透明边框，以便辨认拖动范围。

    悬浮遥控拖至视口任一边缘24dp以内后松手，会吸附到该边缘；其他位置仍可自由放置。在「功能 → 设置 → 悬浮遥控」调节透明度（60–90%，数值越大越透明），立即生效并在重启后保留，普通与全屏预览共用。闲置5秒后自动淡化，触摸立即恢复；按住、拖动与编辑文字时不会淡化。

    安装并启用配套 AIRC 输入法后，在电视选中文字输入框，预览页底部会显示“输入文字”。点击打开手机输入面板和键盘，可发送中文、删除、回车及操作方向键；失焦或断连后入口消失。不自动打开键盘、切换电视输入法或发送内容。

    预览按控制端 H.264 解码器能力开启低延迟模式；不支持该能力的软件解码器使用正常解码模式。
